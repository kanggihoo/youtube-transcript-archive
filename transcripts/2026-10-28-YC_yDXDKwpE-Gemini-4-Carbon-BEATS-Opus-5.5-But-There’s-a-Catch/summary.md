# Gemini 4 Carbon BEATS Opus 5.5 But There’s a Catch!

## 결론부터

Google DeepMind의 신규 모델 Gemini 4 Carbon을 소개하는 뉴스형 영상입니다. 발표자는 발표사 벤치마크에서 Claude Opus 5.5를 앞선다고 전하지만, 모델이 아직 출시 전이라 실제 성능은 출시 후 직접 테스트해야 알 수 있다고 봅니다.

## 핵심 내용

- **벤치마크 수치:** 발표사가 공개한 수치를 옮겼습니다. Terminal Bench는 직전 모델 Gemini 4 Argon의 57.1%에서 65.2%로 올랐고, Opus 5.5(87.2%)가 앞서는 OSWorld 2.1에서는 81.5%입니다. Artificial Analysis Intelligence Index v5에서는 59점으로 Opus 5.5(58점)보다 약간 높지만, 코딩 에이전트 지수에서는 Opus 5.5와 Claude Code(62점)에 뒤져 있습니다. 발표자도 이 지수들을 정확히 계산한 것이 아니라고 밝혔습니다.
- **가격:** 도입 기간 가격은 입력 백만 토큰당 $2, 출력 백만 토큰당 $10입니다. 각주에 따르면 $4와 $20로 오르며, 도입 기간이 언제 끝나는지는 공개되지 않았습니다.
- **출시 전 상태와 추측:** 모델 출시는 몇 주 뒤로 예상되며, 발표자는 Argon의 전례로 11월 중하순을 짐작합니다. 데미스 하사비스의 "lightning speed 반복" 발언과 직원들의 게시물을 근거로 자동 개선(RSI) 가능성을 언급하지만, 발표자 스스로 확인되지 않았다고 말합니다. Frontier Code 2.0에서 익명 모델 Obsidian 3가 Opus 5.5보다 조금 높은 점수를 얻었다는 내용도 있으나, 특정 모델이라는 확인은 없습니다.

## 배울 점과 적용 조건

- **벤치마크는 지수와 작업 유형별로 봅니다.** 이 영상에서 Gemini 4 Carbon은 9개 지수 중 4개에서 1위지만, 코딩 에이전트와 지식 노동 지수에서는 1위가 아닙니다. 작성자 보충으로, 모델 선택은 실제로 쓸 작업(코딩 에이전트, 문서·지식 업무 등)에 맞춰 지수를 골라 보는 편이 안전합니다.
- **도입가와 정가를 구분합니다.** 도입 가격으로 비용을 계산하면 기간이 끝난 뒤 비용이 두 배가 될 수 있습니다. 적용 전에 가격 정책의 만료 시점을 공식 문서에서 확인해야 합니다.
- **출시 전 발표는 결론을 미룹니다.** 영상도 벤치마크만으로 우열을 단정하지 말고 실제 출시 후 비교를 기다리라고 권합니다. 적용 조건은 실제 접근 가능 여부와 본인 작업에서의 재현 결과입니다.

## 근거와 한계

- **영상의 근거:** 발표사 발표 화면의 벤치마크 수치, Artificial Analysis 지수 결과, 공개된 가격표 각주, 발표자 본인의 관찰이 근거입니다. 모델을 직접 실행하거나 시연한 장면은 없습니다.
- **평가:** 수치는 발표사 공개치와 제3자 지수를 인용한 것이며 발표자가 재현하지 않았습니다. 평가 조건(도구, 에이전트 구성, 반복 횟수, 모델 버전)이 제시되지 않아 Argon과의 2주 차이 비교나 Opus 5.5와의 격차를 그대로 받아들이기 어렵습니다. RSI 관련 내용과 유출 모델 점수는 추측 또는 미확인 정보이므로 결론의 근거로 쓸 수 없습니다.
- **확인 범위:** 자막 기반 평가입니다. 외부 확인은 하지 않았으므로 벤치마크 수치, 가격, 출시 시기는 모두 "영상 내 주장, 외부 미검증"입니다. 영상 당시 정보이므로 현재 상태는 공식 발표와 지수 사이트에서 다시 확인해야 합니다.
- **홍보성:** 중간에 Printify 협찬 구간이 있고, 고지 문구도 있습니다. 쇼핑 판매 관련 내용이 길지만 AI 모델 내용과 분리되어 있어 평가에는 큰 영향이 없습니다.
