# Replace ElevenLabs, Jira, Slack & Granola for Your AI Agents (Free on GitHub)

## 한 줄 요약

발표자는 에이전트를 쓰면 쌓이는 구독 비용을 줄이기 위해 Granola, Jira, Notion, Claude Code, ElevenLabs, Firecrawl, Slack을 각각 대체할 수 있는 일곱 가지 무료 오픈소스 도구(Fluid Voice, Paperclip, Basic Memory, free LLM API, Voice Studio, Scrapling, Buzz)를 소개합니다.

## 구독 비용이 쌓이는 이유

- 에이전트를 쓰면 메모, 스크래핑, 프로젝트 관리마다 구독이 필요해져 비용이 불어납니다
- 소개하는 도구는 모두 오픈소스라 무료일 뿐 아니라 커스터마이징이 가능하다는 점을 강조합니다

## Fluid Voice (Granola 대체)

- Granola는 무료 사용자가 오래된 메모를 잃고, 오디오 녹음 없이 텍스트 전사만 제공하며, 팀원이 늘면 비용이 오릅니다
- Fluid Voice는 기기 내 처리로 프라이버시와 속도를 확보한 무료 오픈소스 받아쓰기 앱으로 시작했고, 사용자 요청으로 회의 녹음 기능인 Fluid Meet를 추가했습니다
- 실시간 전사와 회의 후 전체 녹음, 에이전트가 전사본에 접근하는 방법을 제공합니다. 현재 Mac 전용이고 GitHub 스타는 12,000개입니다
- 발표자는 Windows 얼리 액세스 대기자 명단을 제공한다고 말합니다

## Paperclip (Jira 대체)

- Jira는 비용이 쌓이고 설계를 따라야 하며 에이전트 우선으로 만들어지지 않았다는 점을 문제로 듭니다
- Paperclip은 에이전트 우선 조직으로 시작해 사람과 에이전트가 함께 일하게 하고, Claude Code, Codex, Cursor, Open Claw, Gemini 등을 에이전트로 채용합니다
- 칸반 보드, 조직도, 회사별 예산 설정, GitHub와 Notion 연동을 제공하며 스타가 10만 개를 넘었습니다
- 아쉬운 점으로 클라우드 버전과 모바일 앱이 없고 컴퓨터를 계속 켜 둬야 한다는 점을 꼽습니다. Claude나 OpenAI 구독 비용은 별도입니다

## Basic Memory (Notion 대체)

- Notion은 AI 크레딧이 빨리 소진되고, 사람이 늘수록 비용이 오르며, 팀 밖 사람을 실수로 추가하게 만드는 버튼이 있다고 지적합니다
- Basic Memory는 데이터베이스와 임베딩 없이 내 폴더의 평범한 markdown 파일과 위키 링크로 에이전트 지식을 저장하고, 여러 에이전트가 직접 연결됩니다
- 명령어 하나로 설치하며 월 15달러의 호스팅 옵션이 있습니다. 사람이 쓰기에는 즐겁지 않지만 에이전트가 문서를 보는 비중이 커지고 있다고 말합니다

## Zapier (스폰서)

- 반복적인 단순 작업에 고성능 에이전트를 쓰면 비용이 낭비되므로, 이를 코드로 처리하는 Zapier의 next-gen zaps로 넘기면 비용이 줄고 신뢰성이 높아진다고 설명합니다

## Free LLM API (Claude Code 비용 절감)

- 여러 제공업체의 무료 LLM 사용량을 하나로 묶어, 하나가 소진되면 다음으로 넘어가게 하는 도구이며 635개를 엮을 수 있습니다. 더블린의 Microsoft 제품 디자이너가 개인 시간에 만들었습니다
- DeepSeek 같은 모델은 쓰되 Anthropic 모델은 무료로 제공되지 않습니다. 같은 모델을 파는 다른 제공업체로 넘어가므로 전환을 알아채기 어렵다고 합니다
- 개인 에이전트를 만드는 용도이며, 자기 소프트웨어에 내장해 사용자에게 제공하면 안 됩니다. 연 19달러 애드온은 무료 모델에 더 일찍 접근하는 것뿐이라 필수가 아닙니다
- 데스크톱 앱과 Android 옵션이 있습니다

## Voice Studio (ElevenLabs 대체)

- ElevenLabs는 재시도와 수정마다 크레딧이 소모되고 지원에 대한 불만이 있다고 말합니다. 전문적인 판매용이나 클라이언트 작업이라면 지불할 만하다고 인정합니다
- Voice Studio는 무료 AI 음성 모델 Omni Voice(600개 이상의 언어)를 바탕으로 하며, 스타가 61,000개입니다
- 짧은 클립에서 음성을 복제하고, 대본을 읽어 주고, 영상을 다른 언어로 더빙하며, 문서 낭독, 팟캐스트, 책의 오디오북 변환에 쓸 수 있습니다
- 프로 버전은 연 99달러로 상업용 라이선스를 추가합니다. 최근 Mac이나 Nvidia 그래픽 카드(6GB 메모리)가 있는 PC에서 가장 잘 돌아가고, 디스크 여유 공간 10GB가 필요합니다

## Scrapling (Firecrawl 대체)

- Firecrawl은 안 쓴 크레딧이 매달 사라지고, 봇 탐지기에 막힌 페이지도 크레딧을 소모하는 점이 문제라고 합니다
- Scrapling은 이집트의 개발자가 만든 Python 라이브러리로 스타가 87,000개이며, stealth fetcher로 Cloudflare 검사를 통과하고 명령줄에서 코드 없이 페이지를 깨끗한 markdown으로 바꿉니다
- 스크래핑에 완벽한 도구는 없다고 단서를 달며, 차선책으로 Crawl 4 AI를 언급합니다

## Buzz (Slack 대체)

- Slack은 비용이 비싸고, 읽은 메시지와 읽지 않은 메시지를 에이전트가 볼 수 없는 등 에이전트 접근을 제한한다고 비판합니다
- Buzz는 Block(Square, Cash App 제작사)에서 나온 팀 채팅으로 스타가 35,000개이며, 에이전트가 자기 자리를 갖고 멘션할 수 있고 시스템 안에서 Hermes나 Claude Code 에이전트를 만들 수 있습니다
- iPhone과 Android 앱, 채널, 스레드, 다이렉트 메시지, 로컬 모델 지원을 제공합니다. 출시 이후 관심이 줄었지만 데이터가 내 것이라 사라져도 다른 플랫폼으로 옮길 수 있다고 봅니다
