# Muse Wonder Full (Fully Tested): META's BIGGER MODEL vs Opus 5.5, GPT-6 Astra & Sol on KingBench 4!

## 한 줄 요약

AICodeKing은 Meta의 Muse Wonder Full에 KingBench 4 프로젝트 여섯 개를 시켜 60점 만점에 31.8점(53.0%)으로 7개 모델 중 5위, 표준 Wonder(45.8%)보다 약 7.2퍼센트포인트 높다고 평가하지만, 토큰은 약 74%, 생성 시간은 약 3.8배 더 들고 최고 결과물도 직접 검증이 필요하다고 말합니다.

## 실험 조건

- 에뮬레이터, 도커 대안, 3D 방 디자이너, 키보드 설정 도구, 포켓몬 게임, 핏빗 앱을 같은 요청과 같은 네이티브 Muse CLI, 높음 추론, 새 프로젝트 폴더로 만들게 했습니다
- Full은 표준 Wonder에서 최대 추론을 골라도 바뀌지 않는 별도 변형이며, 월 50달러·200달러 구독으로 제공되고 종량제 요금은 없습니다. 비용 추정은 표준 Wonder 요율을 그대로 적용한 가정치입니다
- 완성된 파일을 고정해 복사본을 테스트했고, 점수 전에 앱을 고치지 않았습니다. Muse 실행에는 추가 제한 시간이 없었고, 이전 모델들은 다른 도구와 60분 감시 장치를 썼으므로 비교가 모든 조건 차이를 걸러내지는 못합니다

## 공개 벤치마크는 대체로 Full이 앞선다

- Vals 지수는 Full 64.57%(5위), 표준 Wonder 61.06%(10위)이고, Terminal Bench 4는 Full 58.08%로 5위이며 Fable과 동률입니다
- Vibe Code Bench는 Full 86%(12위), 표준 83.09%(18위)이고, 코드 마이그레이션은 Full 61.03%로 표준 62.55%보다 낮습니다
- Artificial Analysis 지능 지수는 56 대 52, 코딩 에이전트 지수는 68 대 63입니다

## 과제별 결과

- **에뮬레이터 3.1점(표준 2.4)**: 게임보이 진단 29개 중 23개를 통과하고 CPU 테스트 11개를 모두 통과하지만 타이머, 인터럽트, 상태 복원 오류가 있습니다. DS는 제한적이고 3DS는 더 좁으며, 되감기는 100개 상태에 약 14.1GB가 됩니다
- **도커 대안 Lightbox 3.0점(표준 3.0)**: 이미지 가져오기가 심볼릭 링크를 통해 저장 경계 밖에 쓰고, 내보낸 이미지는 해시 불일치로 거부되며, 도커와 비교한 성능 측정이 없습니다
- **방 디자이너 Atelier 7.0점(표준 7.6)**: 편집, 조명, 가져오기와 내보내기는 쓸 만하지만 피트 단위 입력이 미터로 동작하고, 자동 저장이 마지막 동작을 놓치며, 반복 편집에 그래픽 리소스가 누수됩니다
- **키보드 설정 Hive Key 5.5점(표준 3.5)**: 기본 리매핑과 재연결은 동작하지만 레이어 키 코드, 인코더 방향, 매크로, 조명 쓰기가 틀리고 UI는 성공으로 표시합니다
- **포켓몬 7.8점(표준 7.2)**: 처음부터 플레이해 시작, 전투, 회복, Brock 패배와 승리, 저장 이어하기까지 실제로 통과했습니다. 약점은 맵과 포켓몬 그래픽의 충실도, 단순화된 메커닉입니다
- **핏빗 앱 Pulseboard 5.4점(표준 3.8)**: 보기 좋은 대시보드와 재시작 후 유지되는 저장은 좋지만, 가져오기와 프로필 변경이 계산에 반영되지 않고 날짜 구간과 수면 처리 오류, 밀리초 단위 오류가 있으며 데스크톱 패키지는 없습니다. OAuth는 실제 로그인으로 확인하지 못했습니다

## 순위

- Opus 5.5 57.8%, GPT6 Astra 56.5%, GPT 6.1 Sol 55.0%, Haiku 5.5 54.2%, Full 53.0%, 표준 Wonder와 GLM 5.3이 45.8%입니다
- Full은 네 프로젝트에서 나아지고 하나는 같고 방 디자이너에서만 뒤처집니다. 가장 크게 나아진 것은 키보드 설정 도구와 피트니스 앱입니다
- 개별 행이 최종 순위보다 많은 것을 알려 줍니다. Opus는 종합 1위지만 포켓몬은 3.0점입니다

## 토큰, 비용, 시간

- Full은 호출 333회에 약 3,054만 토큰으로, 표준 Wonder의 248회 약 1,756만 토큰보다 약 74% 많습니다. 이 중 캐시된 입력이 2,928만 개이고 새 입력은 약 86만 1천 개, 출력은 약 39만 7천 개입니다
- 표준 Wonder 요율 기준 추정은 Full 17.25달러, 표준 10.52달러로 약 6.73달러(64%) 차이입니다. 컨테이너 프로젝트가 약 5.12달러로 가장 크고도 3.0점에 그친 반면, 에뮬레이터는 Full이 더 싸게(약 2.87달러 대 3.97달러) 더 많은 점수를 받았습니다
- 이전 모델 비용 집계는 세 프로젝트 기준이라 여섯 프로젝트 비용과 순위로 직접 비교할 수 없습니다
- 동시 두 작업 기준 생성 시간은 Full 약 58분 36초, 표준 약 15분 34초로 약 3.8배이며, 에이전트의 명령과 도구 작업이 포함됩니다

## 결론과 사용 판단

- 이 여섯 프롬프트에서는 Full이 전반적으로 더 나은 애플리케이션 세트를 만들었고, 구독이 있고 더 기다릴 수 있다면 다시 시도할 때 Full을 쓰겠다고 합니다. 방 디자이너는 표준 모델 결과를 유지하겠다고 합니다
- 프롬프트 하나로 완성된 에뮬레이터, 컨테이너 플랫폼, 믿을 만한 건강 앱이 나오리라 기대하고 요금제를 사지는 않겠다고 하며, 가장 좋은 결과도 직접 플레이하고 설정을 바꾸고 데이터를 다시 불러와 확인해야 한다고 말합니다
