# 마누스 2.0과 Cue 등장... 패치의 반도체 게임부터 홍보 영상까지 | AI 직원들이 서로 일을 넘긴다… 광고 메일 정리부터 여행 일정 점검

## 한 줄 요약

안될공학의 패치가 마누스 2.0으로 반도체 게임과 트레일러, 채널 인트로 영상을 만들고, 같은 인프라 위의 새 앱 Cue에서 AI 에이전트 팀에게 광고 메일 정리와 여행 일정 점검을 맡겨 본 사용기입니다. 발표자는 도구를 계속 쓸지는 작업 사이에 직접 해야 하는 일이 얼마나 줄어드느냐에 달렸다고 봅니다.

## 대화로 게임을 만들고 플레이하며 다듬기

- 마누스 스튜디오의 게임 개발(Game Dev) 기능으로 캐릭터, 규칙, 아트 스타일을 설명해 패치가 DRAM을 모으며 메모리 부족부터 파운드리까지 세 스테이지를 클리어하는 횡스크롤 게임을 만들었습니다
- 완벽한 기획서를 먼저 쓰는 대신 미리보기에서 직접 플레이하며 달리기 동작, 점프 높이, 화면 이동, 배경과의 상호작용을 하나씩 고쳐 나갔습니다
- 3D 게임도 비슷한 방식으로 만들었고, 공유와 함께 플레이하는 기능도 지원합니다
- 에이전트가 코드를 쓰고 파일을 만들고 실행 결과의 오류를 고치는 작업 공간을 샌드박스라 부르며, 마누스가 이 실행 환경까지 제공합니다

## 영상 제작: 알케미와 비디오 에디터

- 플레이 화면 녹화와 이미지를 넣어 게임 트레일러를, 패치 캐릭터와 채널 에셋으로 안될공학 인트로를 만들었습니다
- 영상이 길어져도 각 구간을 동시에 생성하고, 참고 영상을 주면 색상 팔레트, 움직임, 화면 구성까지 따라 합니다. 말로 설명하기 어려운 연출을 참고 영상으로 전달할 수 있다는 점이 핵심입니다
- 알케미는 영상 생성과 코드 생성을 함께 씁니다. 배경 장면은 영상 모델이, 타이틀과 움직이는 도형, 숫자 기반 그래프는 코드가 만들고 렌더링합니다
- 데스크톱 스튜디오의 비디오 에디터 타임라인에서 클립, 텍스트, 오디오를 직접 고친 뒤 그 상태로 다시 마누스에 넘길 수 있습니다. 처음에는 말로 크게 요청하고 마지막에는 손으로 정밀하게 조정하는 흐름입니다

## 캐스케이드와 에이전트 팀

- 마누스의 최신 에이전트 실행 시스템 캐스케이드는 독립적인 작업을 병렬로 나누고 필요한 전문 기능을 불러 쓰며, 브리프, 페이지, 영상을 한 프로젝트 안에서 관리합니다
- 일을 나누는 것만으로는 부족하고 결과를 주고받으며 기준을 맞추고 정리하는 과정이 필요합니다. 잠깐 쓰는 서브 에이전트와 역할이 정해진 에이전트 팀을 구분할 수 있고, 후자에 초점을 맞춘 앱이 Cue입니다

## Cue로 만든 두 팀

- Cue는 마누스와 같은 인프라 위의 별도 앱으로, 모바일과 데스크톱에서 개인 에이전트를 만들고 프로젝트별 그룹으로 함께 일하게 합니다. 에이전트는 각자 이메일 주소와 컴퓨터를 가질 수 있고, 지역과 약관에 따라 전화번호나 디지털 지갑도 쓸 수 있습니다
- 안될공학 광고팀은 광고 협업 메일을 읽고 요약하고 답장까지 쓰도록 구성했습니다. 한 에이전트가 그룹 채팅에서 일이 끝났다고 알리면 다른 에이전트가 다음 단계를 이어 갑니다
- 여행팀은 받은편지함의 항공권과 숙박 예약 메일만으로 일정 충돌과 빠진 준비를 찾았고, 판단 근거가 된 메일도 함께 정리했습니다. 호주와 상하이 항공편 사이의 충돌, 인스파이어 호텔 예약의 인원별 포함 사항, 이탈리아 숙소와 교통편의 추가 확인 항목을 짚었고, 대시보드 디자이너가 이를 웹페이지로 만들었습니다
- 팀 화면에서 역할을 정의해 두면 매번 처음부터 설명할 필요가 없습니다
- 범위는 읽고, 교차 확인하고, 결정에 필요한 내용을 정리하는 데까지였습니다. 메일 발송이나 답장, 항공과 호텔 예약 변경은 하지 않았습니다

## 이벤트 자동화, Flex 모드, 그 밖의 기능

- 정해진 시간에 실행하는 예약 작업에 더해, 연결된 서비스에서 특정 이벤트가 생기면 작업이 시작되는 방식이 추가됐습니다. 광고 문의가 오면 요구 사항과 마감일을 정리하고, 지정한 뉴스레터가 오면 핵심과 원문 링크를 모으는 식이며 필터로 반응 대상을 정합니다
- Flex 모드는 지원되는 제공업체의 API 키를 연결해 평소 쓰던 모델을 마누스 환경에서 쓰는 방식입니다. 모델 사용료는 해당 제공업체가 청구하고, 마누스의 서비스와 인프라 이용에는 크레딧이 쓰입니다
- 서버가 계속 돌아야 하는 프로젝트용 클라우드 컴퓨터, PC 데이터를 다루는 컴퓨터 사용 기능, 모바일 원격 제어, 문서와 스프레드시트와 PDF와 슬라이드를 다루는 환경도 있습니다

## 도구를 계속 쓸 기준

- 결과물을 다시 붙여 넣고, 이전 결과를 정리하고, 진행 상황을 손으로 기록해야 한다면 결국 사람이 모든 일을 하게 됩니다. 발표자는 앞으로 AI에게 일을 맡길 때 그 중간에 자신이 처리할 일이 얼마나 줄어드느냐를 기준으로 삼겠다고 합니다
