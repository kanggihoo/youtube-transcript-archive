# Claude Mods Are Insane... You Need To Try These Right Now

## 한 줄 요약

AI Labs가 Anthropic의 Claude mods로 직접 만든 Claude Code 모드 일곱 가지(프롬프트 개선, 디자인 시안 미리보기, 가정 점검, 아이디어 보관, 세션 대시보드, 같은 폴더 세션 추적, 쉬운 답변)를 소개합니다. 모드는 Claude Code 자체의 화면과 동작을 바꾸며, 내장된 plugin authoring 스킬에 원하는 바를 말하면 Claude가 만들어 줍니다.

## 모드는 스킬이나 플러그인과 다르다

- Claude mods는 Claude Code 안에서 도는 플러그인이지만, 기능을 더하는 데 그치지 않고 Claude Code가 보이고 동작하는 방식을 바꿉니다. 입력창 옆 패널이나 위의 버튼 바를 그리고, 동작 줄이나 질문 상자 같은 화면 일부를 다시 그리고, 워크플로나 기존 기능의 동작을 바꿀 수 있습니다
- 스킬과 플러그인은 기존 능력에 더하기만 하지만, 모드는 항상 켜져 있어 내장 기능처럼 매번 자기 일을 합니다. 화면 수정은 스킬이나 플러그인이 못 하는 일입니다
- Claude Code에는 이미 모드 두 개가 내장되어 있습니다. 마지막 병합 이후의 변경을 보여 주는 diff 명령과, 사이드 에이전트가 긴 세션에서 놓치기 쉬운 중요한 사항을 명령줄 위 메모로 알려 주는 "you should know"(기본 꺼짐)입니다
- 다른 사람이 만든 모드는 claudmod.com의 마켓에서 쓸 수 있습니다

## 모드 만드는 법

- 최신 Claude Code에는 내장 스킬 plugin authoring이 있습니다. 모드가 무엇을 해야 하는지 말하면 Claude가 이 스킬을 불러와 코드를 씁니다
- 핫 리로드를 허용하면 Claude가 턴을 끝내자마자 모드가 로드되어 바로 확인할 수 있습니다
- 만든 직후에는 일정 시간 뒤 지워지는 임시 위치에 있어 그 세션에서만 쓸 수 있습니다. 다른 세션에서도 쓰려면 Claude에게 설치해 달라고 하면 됩니다

## 프롬프트를 보내기 전에 고치는 개선기

- 대략적인 아이디어만 주면 Claude가 첫 시도에서 방향을 못 잡는 문제를 겨냥합니다. 입력창 위의 개선(Enhance)과 보내기(Send) 버튼 중 개선을 누르면, 프롬프트를 프로젝트와 설치된 스킬에 맞게 입력창에서 바로 다시 써 줍니다
- 직접 보내지는 않으므로 검토하고 고친 뒤 보낼 수 있습니다. 맞는 스킬을 지정하고, Claude가 먼저 물어봐야 할 큰 결정을 나열하고, 최종 결과물의 모습을 설명합니다

## 말 대신 시안을 보여 주는 디자인 선택기

- Claude가 디자인 스타일을 말로만 설명하면 좋아 보여서 골랐다가 실제로 만들어진 결과가 별로인 경우가 많았습니다
- 이 모드는 Claude가 스타일 옵션을 물을 때 옆 패널에 각 옵션의 모습을 보여 주고, 보고 고르면 Claude가 만들기 시작합니다

## Claude의 작은 가정을 드러내는 점검기

- Claude는 큰 결정만 묻고 작은 결정은 스스로 가정하는데, 가끔 틀려서 나중에 뭔가 깨질 때까지 모를 수 있습니다
- 작업이 끝나면 입력창 위 바에 가정의 개수가 표시되고(예시에서는 여섯 개), 입력창이 빈 상태에서 0을 누르면 전체 목록이 열립니다. Tab으로 이동하며 각각을 맞음 또는 틀림으로 표시합니다
- 틀림으로 표시하면 그 가정에 대한 새 프롬프트가 자동으로 Claude에게 가고, Claude는 맞다고 표시한 부분은 두고 그 부분만 고칩니다. 목록에 구체적인 말을 적을 수도 있습니다

## 집중을 깨지 않는 아이디어 선반

- 작업 중 떠오른 아이디어를 Claude의 주의를 흩뜨리지 않고 선반에 올려 두었다가 나중에 보냅니다. 메모 앱에 적으면 잊고 추적이 어려웠던 문제를 풉니다
- 프로젝트마다 선반이 따로 있고 Claude Code를 닫아도 저장됩니다. idea 명령으로 상자를 열어 추가하고, 보내기를 고르면 아이디어가 프롬프트로 Claude에게 갑니다. 필요 없으면 삭제합니다

## 여러 세션을 한눈에 보는 대시보드

- 같은 폴더인지와 상관없이 실행 중인 모든 Claude Code 세션을 보여 줍니다. 나를 기다리는 세션, 작업 중인 세션, 끝난 세션이 구분되고, 세션별로 독립적으로 갱신되어 끝나면 완료 표시가 붙습니다
- sessions 명령이나 Control+X 다음 Tab으로 세션별 워크플로를 볼 수 있고, 내 응답이 필요한 세션을 바로 알 수 있어 세션이 대기 상태로 묶여 있지 않습니다

## 같은 폴더의 세션이 겹치지 않게 하는 추적기

- 같은 프로젝트에서 세션을 둘 이상 돌릴 때 두 세션이 같은 일을 하지 않도록, 각 세션이 지금 무엇을 하고 다음에 무엇을 할지 추적합니다
- 세션이 하나면 평소와 같고, 같은 폴더에 두 번째 세션을 열면 다른 세션이 있다는 알림과 그 세션의 작업, 진행 중인지 완료인지가 표시됩니다. 두 번째 세션에 일을 맡기면 첫 번째 세션 화면에도 그 내용이 나타납니다

## 전문 용어 없이 한 번에 읽히는 답변

- Claude의 답은 전문 용어가 많고 반복적이며, 여러 세션을 돌리면 맥락을 놓쳐 위로 스크롤해야 합니다. 이 모드는 Claude가 기술 용어로 쓴 답을 단순하게 다시 쓰게 합니다
- 다른 세션에서 온 사람도 바로 이해할 만큼 포괄적으로, 다음 단계까지 담습니다. 도구 호출 사이의 짧은 요약은 놓치기 쉬우므로 나오지 않게 하고 끝의 요약에만 텍스트를 둡니다. 규칙을 지켰는지는 Haiku 모델로 확인합니다
- 작업 중인 세션으로 옮겨 가도 무엇을 하는지 알 수 있게 상태 줄도 있습니다
