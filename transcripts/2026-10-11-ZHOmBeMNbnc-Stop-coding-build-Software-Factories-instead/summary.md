# Stop coding, build Software Factories instead

## 한 줄 요약

David Ondrej는 이제 병목이 모델이나 토큰이 아니라 사람이므로, 에이전트를 하나씩 돌리는 대신 트리거로 자동 시작되는 에이전트 루프를 모은 소프트웨어 팩토리를 클라우드 샌드박스에서 돌려야 한다고 주장하고, 자신이 만드는 오픈소스 Cloudroom을 시연합니다.

## 사람이 할 일은 고수준 업무

- 모델은 학습 데이터에 없는 감각 신호, 실용적 판단(시간과 자원 배분), 취향이 약합니다. 이 영역과 제1원리 사고가 사람의 몫이고, 모델이 더 잘하는 일에 매달리지 말라고 합니다
- 농업 인구가 1800년 미국 노동자의 75% 이상에서 2% 미만으로 줄었듯 사람은 늘 적응해 왔으니 두려워하지 말라고 합니다
- 앞으로의 일은 에이전트 함대 운영, 자원 배분, 작업별 모델 선택, 평가와 벤치마크로 CEO나 매니저가 하는 일에 가깝습니다

## 병목은 사람

- 에이전트가 너무 빨라져서 사람이 하나씩 시작하고 지시하는 방식으로는 5개 이상 돌리기도 어렵습니다. 그는 스레드 수백 개가 자신을 기다리고 있어 자신이 에이전트를 막고 있다고 말합니다
- 에이전트 루프는 트리거(일정, 웹훅, 장애, 고객 행동)와 실행(스킬, 컨텍스트, API)으로 이루어지고, 소프트웨어 팩토리는 이런 루프 여럿이 병렬로 도는 것입니다
- 시작은 내 일의 5%입니다. 예측 가능하고 안전한 반복 업무를 고르되, 먼저 시간 추적으로 시간이 어디에 가는지 파악합니다
- 프롬프트 템플릿에서 스킬로, 앞으로는 관찰된 행동 확률에 기반한 스킬 시퀀스로 갈 것이라는 예측이며, 이것이 향후 6개월의 주류라고 봅니다

## 로컬 에이전트의 한계와 클라우드 에이전트

- 노트북은 자원이 한정되고, 닫거나 Wi-Fi가 끊기거나 배터리가 나가면 에이전트가 멈추며, 컴퓨터 사용 에이전트는 화면을 방해하고, 침해되면 모든 자격 증명을 잃습니다. 샌드박스는 침해돼도 그 환경만 영향을 받습니다
- 인용한 Cursor 내부 연구에서 클라우드 에이전트가 낸 PR 비율은 연초 10%에서 8월 60%로 늘었고, 곧 90%에 이를 것이라고 봅니다. 95% 이상의 작업은 클라우드가 낫지만 프라이버시나 폴더 정리처럼 로컬이 나은 경우가 있다고 합니다
- 기존 클라우드 에이전트는 대부분 클로즈드 소스이고 구독, 모델, 도구가 묶이며 시작이 느리다는 점이 문제라고 하고, 그 대안으로 어떤 모델과 구독도 쓰고 로컬만큼 빨리 시작하는 Cloudroom을 만들고 있습니다

## 그가 돌리는 자동화 사례

- 청구 코드 감사(4시간마다), 데이터베이스 상태 점검, 90분마다 침투 테스트 수준의 보안 스캔, 코드베이스 단순화, 테스트 공백 탐지
- 사용자 신고 테이블을 10분마다 확인해 Opus 5.5가 조사하고, 사소하면 요약 후 종료, 중요하면 남겨 두는 흐름. 문제가 없으면 스스로 종료하므로 그의 시간이 들지 않습니다
- 한 모델이 만든 결과를 다른 회사 모델로 적대적으로 검토하게 합니다. 두 모델이 모두 동의할 때만 사람에게 승인을 요청합니다
- 매니저 에이전트가 하위 에이전트 15~25개를 띄우고, Opus를 조정자, Sonnet이나 Haiku를 작업자로 섞는 계층 구성도 보여 줍니다

## 모델과 구독에 대한 의견

- 그는 Opus 5.5를 현재 최고 모델로 보고(AGI라고까지 말합니다), SemiAnalysis 분석을 인용해 200달러 Claude Code 구독이 같은 가격의 Codex 구독보다 약 10배 가치 있다고 말합니다
- API 요금은 내지 말고 구독을 쓰라고 합니다. 꼭 API를 써야 한다면 중국 모델을 권합니다
- 한 모델로 만들면 다른 회사 모델(OpenAI와 Anthropic)로 검토하라고 권하고, 구독 한도를 남기는 것은 토큰을 수익으로 바꿀 줄 모른다는 뜻이라고 말합니다

## 격차와 Cloudroom Ultra 제안

- AI를 잘 쓰는 사람과 평범하게 쓰는 사람의 격차가 벌어지고 있고, 최신 기술을 따라가지 않는 비용이 가장 높다고 주장합니다. 마크다운 파일이나 코드 줄 수를 자랑하는 것은 초보의 신호라고 합니다
- 미래 파악법으로 휴대폰과 컴퓨터 없이 60~90분 동안 제1원리로 생각하고 토론하는 세션을 매일 하라고 권합니다
- Cloudroom Ultra는 월 200달러 요금제를 여럿 쓰는 사업가와 파워 유저가 대상이고, 가입한 처음 약 열 명에게 일대일 교육과 30일 동안 클라우드 에이전트 1만 개를 제공한다고 합니다. 영상은 PostHog 후원을 포함합니다
