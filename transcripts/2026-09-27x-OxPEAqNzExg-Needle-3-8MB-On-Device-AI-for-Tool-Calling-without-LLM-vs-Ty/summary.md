# Needle 3은 작은 기기에서 자연어를 구조화된 도구 호출로 바꾸도록 설계된 오픈소스 모델이다. JSON 형태는 문법으로 보장하지만 호출의 정확성은 별도 문제이며, 프로덕션 용도에는 작업별 도구 설계와 미세 조정이 필요하다고 영상은 강조한다.

## 크기와 출력 방식

전체 모델은 약 29MB이고 일부 층만 사용하는 작은 변형도 제공한다. 스키마를 문법으로 제한해 출력이 파싱 가능한 구조가 되도록 한다. 신뢰도 점수에 따라 자동 실행, 사용자 확인, 호출 보류로 나누는 설계를 제시한다.

## 성능 주장의 한계

영상은 모바일 도구 호출 벤치마크와 미세 조정 결과를 소개하지만 데이터셋이 작고, 자체 시험 결과도 다를 수 있다고 밝힌다. Needle은 범용 비서라기보다 좁은 작업에 맞춘 모델이며, 도구 구성과 미세 조정을 고려해야 한다.

## Needle과 Jev의 역할

Needle은 로컬 실행과 데이터 보관, 무호출 비용에 강점이 있고 Jev는 클라우드에서 더 큰 판단과 선택지 평가를 담당한다. 단순 기기 동작은 Needle, 어려운 라우팅은 Jev가 처리하도록 함께 구성할 수 있다.
