# Claude Code Templates는 에이전트·스킬·명령·MCP 등의 템플릿을 찾고 실제 지침을 확인한 뒤 설치하게 돕는다. 템플릿이 프로젝트에 맞는지 검토하고 필요한 부분을 수정해 작은 반복 작업부터 적용하는 것이 핵심이다.

## 찾아보고 설치하기

카탈로그에서 코드 리뷰 에이전트와 테스트 생성 명령을 골라 스택 빌더로 함께 설치할 수 있다. 설치된 지침은 `.claude/agents`와 `.claude/commands`에 저장되며 프로젝트 관례에 맞게 직접 편집할 수 있다. 스킬은 `.claude/skills`에 들어간다.

## 실제 작업에 사용하고 검증하기

리뷰어에는 범위와 파일 수정 금지 조건을 주고 발견 사항을 재현해 확인한다. 테스트 생성 뒤에는 프로젝트 테스트와 브라우저 동작을 직접 확인한다. MCP·훅·설정은 필요한 권한과 명령을 먼저 살펴야 한다.

## 분석 도구와 주의점

헬스 체크, 사용량 대시보드, 대화 모니터가 포함된다. 분석 비용은 기록 기반 추정치다. 템플릿 컬렉션은 무료지만 모델 사용과 연결된 서비스는 별도 비용이 발생할 수 있다.
