# ChatGPT Sites는 웹사이트, 내부 앱, 고객 분석 보고서, 프레젠테이션, 자동 갱신 대시보드를 만드는 사례를 제공한다. 결과 품질은 의도·브랜드 자료·시각 참고·완료 기준을 처음에 분명히 주고, 외부 연동 자격 증명과 예약 갱신을 설정하는 데 달려 있다.

## 다섯 가지 활용 사례

랜딩 페이지 개편, 기존 도구를 대체하는 내부 앱, 회의 기록 분석, 인터랙티브 영업 덱, 여러 소스 데이터를 결합한 대시보드를 시연한다. Sites에서 만든 결과는 공유하고 사용자 도메인에 연결하거나 예약 작업으로 갱신할 수 있다고 영상은 설명한다.

## 프롬프트와 반복 작업

목표와 맥락, 브랜드 가이드, 참고 디자인, 필요한 섹션, 완료 조건을 프롬프트에 포함한다. 주석 기능으로 특정 UI를 선택해 수정하고, 반복되는 산출물은 스킬로 저장해 재사용한다.

## 외부 서비스 연결

Drive 같은 외부 서비스에는 별도 인증과 환경 변수 설정이 필요하다. 회의 기록·분석 데이터를 다룰 때는 저렴한 하위 모델에 대량 읽기를 맡기고 결과를 근거와 함께 정리하는 방법을 보여준다.
