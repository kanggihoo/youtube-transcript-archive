# 한국어 번역

오늘은 새로운 ChatGPT Sites 기능을 이용해 웹사이트, 대시보드, 프레젠테이션, 앱까지 ChatGPT 안에서 만드는 방법과 다섯 가지 활용 사례를 소개합니다. 진행자는 사이트 패널에서 만든 결과물을 관리하고 공유하는 모습을 보여줍니다.

## 1. 웹사이트와 랜딩 페이지

Sites 플러그인을 추가해 기존 홈페이지를 새로 디자인할 수 있습니다. 진행자는 디자인 작업에 GPT-6 Astra를 권하며, 처음 프롬프트에 더 공을 들이면 반복 수정을 줄이고 좋은 결과를 얻을 수 있다고 말합니다. 프롬프트에는 다섯 가지를 넣으라고 권합니다.

1. 왜 개편하는지, 현재 무엇이 문제인지 등 의도를 설명합니다.
2. 브랜드 색상, 로고, 자산과 사업 맥락을 제공합니다. 프로젝트 폴더에 디자인 가이드가 없으면 ChatGPT와 `design.md`를 만들 수 있습니다.
3. 원하는 디자인의 참고 링크나 이미지를 줍니다. Dribbble이나 템플릿에서 시각 자료를 고를 수 있습니다.
4. 필요한 섹션을 지정하거나 기존 사이트의 요소를 유지하도록 합니다.
5. 완료 기준을 정해 모델이 불필요한 작업을 계속하지 않게 합니다.

첫 결과는 라이브 URL이나 ChatGPT 사이트 창에서 볼 수 있습니다. 주석 기능으로 수정할 요소를 직접 선택해 메뉴, 색, 스크롤 애니메이션 등을 바꿀 수 있습니다. 완성된 사이트는 기본 호스팅 링크 대신 사용자 도메인에 연결할 수 있습니다.

## 2. 내부 앱 만들기

Sites에는 데이터베이스, 분석, 환경 변수와 인증 정보 기능이 있어 내부 앱을 만들거나 기존 소프트웨어를 대체할 수 있다고 소개합니다. 진행자는 광고가 많고 느리며 링크를 하나씩 넣어야 했던 YouTube 썸네일 다운로드 앱을 직접 다시 만들었습니다. 한 번에 최대 100개 링크를 넣고 썸네일을 렌더링해 지정한 Drive 폴더에 저장하도록 했습니다.

만들 앱의 목적과 저장 위치, 대체할 기존 앱 링크, 부족한 기능, 브랜드 가이드를 프롬프트에 제공합니다. 외부 소프트웨어에 연결할 때는 API 자격 증명을 직접 설정해야 합니다. 일반 API는 서비스 설정에서 키를 만든 뒤 Sites 앱의 환경 변수에 보관해 연결할 수 있습니다. Google Drive는 인증 설정이 더 복잡했다고 설명합니다.

## 3. 고객 데이터 분석 보고서

ChatGPT 플러그인으로 회의 기록을 가져와 고객 인터뷰를 분석하는 사례입니다. 데이터가 많을 때는 하위 에이전트에 더 저렴한 GPT-5.6을 사용하도록 지시하고 GPT-6는 보고서 작성에 쓰는 규칙을 넣었습니다. 116건의 고객 지원 통화를 32분간 분석해 고객의 주요 문제를 근거 인용과 함께 제시하는 YouTube 주제 아이디어, 커뮤니티 개선 우선순위, 고객 프로필 보고서를 만들었다고 합니다.

진행자는 Claude에 지난주 회의 기록을 매주 분석하는 예약 작업을 설정하게 했습니다. 팀원은 Sites 패널에서 최신 고객 인사이트 보고서를 공유받습니다.

## 4. 대화형 프레젠테이션

영업 통화와 내부 회의에 인터랙티브 슬라이드 덱을 사용합니다. 영업 덱을 만들 때 기존 프레젠테이션과 `design.md`를 참고로 제공해 브랜드와 구조를 따르게 할 수 있습니다. 슬라이드마다 점진적 정보 공개를 요청하면 요소가 순차적으로 나타나는 효과를 얻습니다. 완성된 덱 형식을 스킬로 저장해 새 잠재 고객용 자료에도 같은 레이아웃을 반복 적용할 수 있습니다.

내부 회의에서는 Whisper Flow 같은 음성 전사 도구로 논의할 내용을 길게 기록한 뒤, 이를 Sites 프레젠테이션으로 구조화합니다.

## 5. 자동 갱신 분석 대시보드

여러 소프트웨어의 데이터를 결합해 최신 정보로 자동 갱신되는 대시보드를 만들 수 있습니다. 진행자는 YouTube 채널 성과 대시보드에 vidIQ 플러그인의 영상 데이터와 PostHog 분석의 전환 데이터를 결합했습니다. 원하는 대시보드와 데이터 출처, 측정 지표의 목적, 참고 디자인을 주고 Sites 플러그인과 ChatGPT Data 플러그인을 사용했습니다. 매일 오전 9시에 새 데이터로 대시보드를 갱신하는 예약 작업도 만들었습니다.
