# Agent-Native + Claude Code: Finally! Apps Your AI Agent Can Actually Work In (Open Source)

## 한 줄 요약

Builder의 오픈소스 TypeScript 프레임워크 Agent Native는 사람이 UI에서 직접 고친 내용을 에이전트가 현재 상태로 이해하고 이어서 작업하게 해 주며, 발표자는 Slides 앱 시연과 액션·컨텍스트 구조 설명으로 이를 보여 줍니다.

## Agent Native가 푸는 문제

- 에이전트가 만든 초안을 채팅으로만 고치지 않고 텍스트를 직접 클릭해 고친 뒤, 에이전트가 그 변경까지 포함한 현재 상태를 이해하길 원한다는 것이 출발점입니다
- React를 쓰고, 원하는 모델을 연결하고, 코드를 자신의 저장소에 두고, 지원되는 호스트에 배포할 수 있습니다

## Slides 앱 시연

- 로그인과 모델 연결은 별개 단계입니다. 시연에서는 Open Router를 연결하고 기본 모델을 선택했습니다
- 템플릿 덱에서 제목을 더블클릭해 고치고 필름스트립에서 슬라이드를 드래그해 옮기는 수동 편집이 가능합니다
- 6장짜리 덱을 프롬프트로 만든 뒤, 사람의 검토 슬라이드 제목과 순서를 직접 바꿨습니다
- 이어서 슬라이드를 더 기술적으로 바꿔 달라고 하면서 수정한 제목을 다시 붙여넣지 않고 지칭했고, 열린 슬라이드를 편집했는지, 새 제목을 보존했는지, 위치가 유지됐는지를 확인합니다
- 문장을 선택해 revise with AI로 요청하면 에이전트에게 대상이 분명히 전달됩니다
- HTML, PDF, PPTX, Google Slides로 내보낼 수 있으나 글꼴과 레이아웃은 달라질 수 있어 확인이 필요합니다

## 직접 실행하기

- Node 22.22 이상과 PNPM이 필요하며, 스타터 명령으로 Slides 템플릿 프로젝트를 만들어 pnpm install, pnpm dev로 실행합니다
- 모델은 builder, 자신의 제공자, 로컬 Ollama 중에서 연결합니다
- 프레임워크는 무료 오픈소스이지만 모델 사용료와 인프라에는 비용이 들 수 있습니다

## 공유 액션 구조

- define action은 description, 입력 schema, 편집을 수행하는 run 함수로 이루어지며, 편집 권한을 확인하고 저장 후 연결된 클라이언트에 알립니다
- React는 use action query와 use action mutation으로 액션을 호출하고, 같은 액션을 에이전트, HTTP, MCP로도 노출할 수 있습니다
- rename draft 같은 액션 하나에 검증 로직을 두면 UI와 에이전트가 같은 규칙을 씁니다
- Slides에서는 브라우저 편집기가 patch deck을, 에이전트가 update slide 같은 전용 액션을 쓰지만 같은 덱과 잠금 메커니즘을 공유합니다

## 컨텍스트 인식

- 인터페이스가 현재 보기와 선택을 제공하고, view screen 액션이 이를 바탕으로 관련 레코드를 가져옵니다
- 유용한 ID 몇 개와 현재 선택부터 연결하는 것을 권합니다. 비슷한 이름의 문서 사이에서 에이전트가 추측하게 두지 않기 위해서입니다
- 초안을 바꿔 가며 같은 요청을 반복해 응답이 실제로 연 대상을 따르는지 검증할 수 있습니다
- 공유 데이터베이스 기반 데이터는 UI와 에이전트가 같은 레코드를 쓰게 하고, 애플리케이션 상태는 현재 선택 같은 것을 담습니다

## Claude Code로 커스터마이즈하기

- 소스가 있으므로 Claude Code나 Codex에 기존 구조를 먼저 살피게 한 뒤 원하는 기능을 평범한 말로 설명해 만들게 할 수 있습니다
- 예로 UI에서 체크하고 덱과 함께 저장되며 내장 에이전트도 공유 액션으로 읽고 고치는 검토 체크리스트를 듭니다
- 한 워크플로를 골라 수동과 에이전트를 번갈아 쓰며 사람의 편집 보존, 최신 결과 표시, 복구 가능 여부를 확인하라고 권합니다

## 한계와 어울리는 용도

- 예제 앱은 알파이고, 에이전트를 연결해도 모든 편집이 좋다는 보장은 없어 모델, 프롬프트, 액션 처리를 평가해야 합니다
- 질문하고 짧은 답을 읽는 용도라면 단순한 채팅으로 충분할 수 있습니다
- 여러 차례 둘러보고 선택하고 편집하고 검토하는 작업, 예를 들어 프레젠테이션, 콘텐츠 캘린더, 문서 편집기에 더 유용하다고 봅니다
