# 한국어 번역

매주 개발자들은 코딩, 자동화, 일상 업무를 빠르게 해 주는 강력한 오픈소스 GitHub 프로젝트를 공개합니다. 이번 주에는 멀티 에이전트 코딩 도구부터 네트워크 인프라, 로컬 우선 앱까지 살펴봅니다. AI 에이전트 전용 채널 AI Agents Studio도 새로 시작했습니다.

## 1. Tiny Cast

작고 무료인 macOS 네이티브 런처로 Raycast의 가벼운 대안입니다. 전역 단축키로 실행하는 검색 팔레트에서 앱을 찾아 열고, 실행 중인 앱을 확인하거나 종료할 수 있습니다. 앱별 포커스 전환 단축키, 텍스트와 이미지 클립보드 기록 검색, 스니펫, 계산기, 사전, Spotlight 파일 검색을 제공합니다. Raycast 확장도 실행하며 메모리 사용량을 엄격히 제한하도록 만들었습니다. Homebrew로 설치할 수 있습니다.

## 2. Cilium

eBPF 기반의 Kubernetes 네트워킹, 보안, 관측성 솔루션입니다. CNI 플러그인으로 클러스터 간 네이티브 라우팅 또는 오버레이 모드의 L3 네트워크를 만들고, IP 주소와 분리된 ID 기반 모델로 L3부터 L7까지 네트워크 정책을 적용합니다. eBPF에서 로드 밸런싱을 수행해 kube-proxy를 완전히 대체할 수 있으며 인그레스·이그레스 게이트웨이, 대역폭 관리, 서비스 메시도 제공합니다. CNCF 프로젝트입니다.

## 3. ECC

Claude Code, Codex, Open Code, Cursor 등 코딩 에이전트가 더 나은 엔지니어처럼 일하도록 돕는 오픈소스 시스템입니다. 스킬, 메모리, 기술 스택별 규칙, 보안, 조사 우선 작업 흐름을 추가해 에이전트가 구현 전에 계획하고 테스트로 변경 사항을 검증하며, 새 컨텍스트에서 자체 검토하고 중요한 내용을 기억하도록 합니다. `review peer`, `learn`, `consult` 명령과 Agent Shield 보안 계층을 제공합니다. 플러그인이나 설정 도구로 설치할 수 있습니다.

## 4. Octop

Tencent Cloud가 만든 셀프 호스팅 멀티 사용자·멀티 에이전트 AI 비서입니다. 로컬 프로세스로 웹 대시보드, CLI, cron 자동화, Feishu, DingTalk, Discord, WeCom 같은 채널을 제공합니다. 사용자마다 작업에 따라 전환할 수 있는 에이전트 팀이 있고 각 에이전트는 별도 작업 공간을 가집니다. 전문가 라이브러리, MCP 커넥터, IDE 도구용 ACP로 확장할 수 있으며 사용자별 격리와 로컬 데이터 보관을 지원합니다.

## 5. Cline

VS Code·JetBrains 확장, CLI, SDK로 제공되는 오픈소스 자율 코딩 에이전트입니다. 프로젝트를 읽고 여러 파일을 함께 수정하며 린터와 컴파일러 오류를 살펴 고칩니다. 터미널 명령을 실행하고 결과에 실시간으로 반응합니다. 계획 모드에서 전략을 세운 뒤 실행 모드가 작업하며, 수정과 명령마다 사용자 승인을 요구합니다. 모델에 종속되지 않고 MCP로 확장할 수 있습니다.

## 6. n8n

AI 기능을 내장한 fair-code 워크플로 자동화 플랫폼입니다. 노드 기반 시각 캔버스에서 앱과 서비스를 연결하고 필요한 곳에는 직접 코드를 작성할 수 있습니다. 400개 통합 기능이 있으며 AI 노드로 LLM 에이전트와 단계를 워크플로에 넣을 수 있습니다. 소스 공개 프로젝트로 Docker나 Kubernetes에 자체 호스팅하거나 n8n Cloud를 쓸 수 있습니다. 커스텀 노드로 확장합니다.

## 7. FirstMate

터미널 코딩 에이전트를 자율 에이전트 팀의 작업 배정자로 바꾸는 에이전트 배포판입니다. 하나의 FirstMate에 요청하면 격리된 Git 워크트리에서 팀원 에이전트를 실행합니다. 토큰을 쓰지 않는 이벤트 기반 감시자가 작업을 감독하고 완료된 PR, 병합 결과 또는 보고서를 돌려줍니다. Claude Code, Grok, P, Codex, Open Code와 tmux 등 세션 백엔드를 지원합니다. 병렬 코딩 작업을 다루는 개발자에게 맞습니다.

## 8. Orca

Claude Code, Codex, Grok, Cursor 등 CLI 코딩 에이전트를 각자 격리된 Git 워크트리에서 병렬로 실행하는 데스크톱·모바일·VPS 앱입니다. 여러 에이전트 작업을 하나의 공간에서 추적하고 하나의 프롬프트를 여러 에이전트에 보내 결과를 비교할 수 있습니다. 임베디드 터미널, 디자인 작업용 브라우저, GitHub와 Linear 검토 기능을 포함합니다.

## 9. Omarchy

에이전트 친화적이고 내장 설명서를 갖춘 Linux 배포판입니다. 테마와 단축키부터 AI, 개발 도구, 네트워킹까지 다루는 상세한 설명서를 제공합니다. 탐색, 받아쓰기, 스크린샷, 설정 파일을 미리 구성해 현대적인 데스크톱을 처음부터 조립하는 부담을 줄입니다. Mac 하드웨어, 듀얼 부팅, 무인 설치, 시스템 스냅샷을 지원합니다.

## 10. OpenLogi

Logitech Options Plus의 로컬 우선 Rust 대안입니다. 계정이나 원격 측정 없이 HID++와 UVC로 Logitech 마우스, 키보드, 웹캠을 제어합니다. 텍스트 설정 파일 하나로 버튼, DPI, 제스처를 로컬에서 재설정합니다. CLI를 제공하고 macOS, Linux, Windows에서 작동합니다. Litra 조명 밝기와 카메라 초점·노출도 조정합니다.

## 11. Voice Studio

음성 복제, 더빙, 받아쓰기 등을 로컬에서 수행하는 오픈소스 음성 스튜디오입니다. 음성 디자인, 영상 더빙, 받아쓰기, 전사, 오디오북 제작을 646개 언어로 지원합니다. CUDA, Apple Silicon, Rockchip, CPU에서 TTS 엔진 16개와 ASR 엔진 11개를 실행해 오디오와 프로젝트를 기본적으로 기기에 보관합니다. 데스크톱 앱, OpenAI 호환 API, 에이전트 통합용 MCP 서버를 제공합니다.

## 12. TimesFM

Google Research의 시계열 예측 사전 학습 기반 모델입니다. 과거 데이터를 받아 작업별 학습 없이 미래 값을 예측합니다. 여러 분야에 제로샷으로 일반화하며 단일 시계열과 다변량 입력, 선택적 과거·미래 공변량을 처리합니다. PyTorch 또는 Apple Silicon용 MLX 패키지를 설치한 뒤 NumPy 배열의 `predict` 함수로 분위수 범위를 포함한 예측을 얻습니다. 수요, 트래픽, 센서 데이터 예측에 활용할 수 있습니다.

## 13. FreeLLMAPI

무료 모델 제공자 34곳의 무료 사용량을 하나의 OpenAI 호환 `/v1` 엔드포인트로 통합하는 셀프 호스팅 라우터입니다. 요청마다 사용 가능한 모델을 선택하고 키별 사용량을 추적하며 제공자의 한도에 걸리면 자동으로 대체합니다. API 키는 AES-256으로 암호화합니다. Claude Code, Codex 등 코딩 에이전트와 함께 쓸 수 있습니다.

## 14. Noto Emoji

유니코드 전체 범위를 지원하는 오픈소스 컬러 이모지 글꼴과 SVG·PNG 벡터 원본 모음입니다. 이모지 글리프가 없어 빈 네모(tofu)가 표시되는 문제를 표준 글꼴로 해결합니다. 컬러 글꼴은 Android, Chrome, Chromium OS에서 기본 지원하는 CBDT/CBLC 형식이며 다른 환경은 일부 지원합니다. 흑백 가변 글꼴도 별도로 유지 관리합니다.

## 15. Rakazo

컴퓨터, 모델, 샌드박스를 갖춘 오픈소스 AI 봇입니다. 각 봇은 하나의 대화, 컴퓨터, 메모리, 루틴을 가집니다. 사용자가 AI 제공자를 직접 선택하고 에이전트 명령을 Docker, E2B 또는 호스트에서 실행할 수 있어 특정 모델·샌드박스에 묶이지 않습니다. 웹·데스크톱·모바일 클라이언트가 같은 API를 사용하며 컴퓨터 화면에는 봇이 제어하는 실시간 Linux 데스크톱이 보입니다.

## 16. JevLike

변하는 텍스트 선택지 목록에 점수를 매기는 단일 패스 모델의 오픈소스 시작 프로젝트입니다. 텍스트와 선택지 목록을 받아 토큰을 차례로 생성하는 대신 한 번에 각 선택지의 확률을 반환합니다. 선택 작업에서 생성형 디코더 모델의 속도 비용을 줄이려는 설계입니다. 선택지를 문맥에 반영하는 질의 벡터로 만들고 공유 내적과 softmax로 확률을 계산합니다. JSONL 자료로 학습하며 자체 바이트 인코더 또는 고정된 Hugging Face 인코더를 사용할 수 있습니다. CPU, Apple MPS, CUDA를 지원합니다.

## 17. @shadcn/lint

디자인 시스템 규칙에 어긋나게 코딩 에이전트가 컴포넌트 스타일을 바꾸는 것을 막는 Tailwind 중심 ESLint·OxLint 플러그인입니다. 타입 검사가 잘못된 코드를 거부하는 데 그치는 문제를 보완해, 프로젝트 컴포넌트·변형·테마에서 가져온 지침과 위반 내용을 연결합니다. 컴포넌트별로 허용 클래스를 정하고 에이전트가 린트를 실행해 실수를 찾아 고치게 합니다. Tailwind v4 프로젝트에서 쓸 수 있으며 shadcn/ui는 필수가 아닙니다.

## 18. Plexo

Wi-Fi, Ethernet, USB 테더링 등 여러 네트워크 인터페이스를 동시에 써서 같은 파일의 조각을 내려받는 macOS Electron 앱입니다. HTTP Range 요청으로 8MB 조각을 나누고 각 연결을 특정 인터페이스에 묶습니다. 작업 분배 대기열은 빠른 네트워크에 더 많은 조각을 맡깁니다. 서버 검증자를 확인해 다운로드를 안전하게 이어받으며, 진행 화면에서 각 네트워크가 받은 조각을 보여줍니다.

## 19. PizzaBot OSS

장시간 실행되는 AI 에이전트의 작업을 정리하는 로컬 우선 받은 편지함입니다. 상태를 유지하는 deep agents와 LangGraph 런타임을 기반으로, 끝난 작업은 읽지 않음으로, 사용자 결정이 필요한 작업은 실행 항목으로 분류합니다. 사용자가 화면을 떠나도 에이전트는 계속 작동합니다. Electron 데스크톱, 브라우저 앱, 터미널 CLI가 로컬 API 서버를 함께 사용합니다. Bedrock, Anthropic, Gemini, OpenAI, OpenRouter, Ollama를 지원하며 기술 범위는 스킬로 확장합니다. 로컬 폴더 접근은 기본 허용하지 않고 명시적으로 부여합니다.

## 20. Bishoures

WebGPU를 지원하면 브라우저에서, 아니면 WebAssembly로 실행하는 오픈소스 배경 제거기입니다. Pin by RefNet Light ONNX 모델을 로컬에서 실행해 서버 업로드, 계정, 사용량 제한 없이 배경을 제거합니다. 브라우저가 모델을 한 번 내려받아 캐시하고 투명 PNG를 생성합니다. `@bishoures/barsh` 패키지는 모델 로딩, 추론, 결과 처리를 웹 앱에 통합합니다.
