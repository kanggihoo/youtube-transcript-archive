# 영상은 코딩 에이전트, 자동화, 로컬 앱, 인프라 등 20개 오픈소스 프로젝트를 짧게 소개한다. 빠른 개요와 탐색 목록으로 유용하며, 각 프로젝트의 실제 적합성은 설명서와 현재 상태를 별도로 확인해야 한다.

## 개발과 에이전트 작업

Claude Code 대안·확장, 에이전트 오케스트레이션(FirstMate, Orca), 코딩 절차·보안 스킬(ECC), 의미 기반 JevLike 분류기, 디자인 시스템 린터 등이 포함된다. OpenLogi와 Omarchy처럼 개발 환경을 구성하거나 기기 제어를 로컬에서 처리하는 프로젝트도 다룬다.

## 자동화와 로컬 우선 도구

n8n은 시각 워크플로와 AI 노드를 제공하고, Octop·Rakazo·PizzaBot OSS는 셀프 호스팅 또는 로컬 기반 에이전트 경험을 제안한다. Voice Studio와 Bishoures는 음성·이미지 처리를 로컬에서 수행하는 도구다.

## 인프라와 데이터

Cilium은 Kubernetes 네트워킹과 보안을, TimesFM은 시계열 예측을 다룬다. RustFS는 S3 호환 오브젝트 스토리지, Supabase는 Postgres 기반 백엔드 플랫폼을 제공한다. GitDiagram은 저장소 구조를 다이어그램으로 보여준다.

## 활용 시 확인할 점

영상은 프로젝트 소개와 사용 맥락에 초점을 둔다. 라이선스, 운영 상태, 지원 플랫폼, 보안·데이터 처리 조건은 각 저장소에서 확인한 뒤 도입해야 한다.
