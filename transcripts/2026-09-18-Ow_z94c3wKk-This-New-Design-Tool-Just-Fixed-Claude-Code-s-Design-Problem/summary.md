# This New Design Tool Just Fixed Claude Code's Design Problem

## 한 줄 요약

코딩 에이전트가 텍스트 마크다운 지침만으로는 시각적 조화를 파악하지 못해 양산형 AI 웹 디자인을 생성하는 고질적 문제를 해결하기 위해, 832개 실전 웹사이트의 고화질 반응형 스크린샷과 수치화된 `design.md`를 제공해 에이전트의 시각적 안목과 합성 능력을 극대화하는 무료 MCP 서버 'Inspo'의 활용법을 소개한다.

## AI 웹 디자인이 천편일률적인 원인과 텍스트 지침의 한계

- **통계적 안전 패턴의 덫**: 모델은 사전 훈련 과정에서 가장 빈번하게 등장한 패턴(예: 흰 배경에 보라/파랑, 크림/주황 조합, 화면을 가득 채우는 거대 텍스트)을 가장 안전한 답으로 인식해 반복 복제함.
- **텍스트 기반 디자인 스킬(Hallmark 등)의 한계**: 마크다운(`.md`) 형태의 폰트·간격 지침만으로는 브라우저 상에서 모든 컴포넌트가 결합되었을 때의 실제 시각적 조화(Visual Harmony)를 모델이 온전히 연상하기 어려움.

## 무료 디자인 MCP 서버 'Inspo'의 핵심 기능

- **검증된 실전 사이트 라이브러리**: 832개 실제 웹사이트에서 수집한 2,320개 캡처 페이지 데이터베이스 탑재.
- **데스크톱 및 모바일 듀얼 스크린샷**: 화면 크기 축소 시 반응형 레이아웃 재배치 방식을 에이전트가 시각적으로 직접 학습.
- **구조화된 `design.md` 수치 데이터**: 정확한 헥스(Hex) 컬러 팔레트, 폰트 패밀리, 텍스트 크기, 마진/패딩 여백을 정량적으로 제공하여 이미지 파싱 오차 제거.
- **컴포넌트 단위 레퍼런스**: 내비게이션 바, 히어로, 가격표, 푸터 등 개별 섹션별 우수 사례 분리 탐색 지원.

## 실전 워크플로 및 합성 메커니즘

- **독창적 디자인 합성**: 단일 사이트를 그대로 복제(Copy-paste)하는 대신, 히어로는 A 사이트, 버튼은 B 사이트, 제품 그리드는 C 사이트에서 영감을 취합해 완전히 독창적인 새 레이아웃으로 조합.
- **UI Skills MCP 연동**: Inspo로 구축된 정적 레이아웃 위에 Emil Kowalski 및 Meng To의 모션 스킬을 결합하여 완성도 높은 마이크로 인터랙션 및 스크롤 애니메이션 구현.

## 실전 사용 시 주의사항 및 모범 사례

- **산업군 필터 명시**: 검색 키워드가 모호할 경우 관련 없는 산업군 레퍼런스가 유입될 수 있으므로 업종 필터를 구체화할 것.
- **사전 시안 승인(Human-in-the-loop)**: 쿠키 동의 팝업 등으로 일부 스크린샷이 가려질 경우 모델이 자의적 상상으로 회귀할 수 있으므로, 코드 작성 전 3가지 디자인 방향성을 먼저 제안받고 승인하는 절차 권장.
