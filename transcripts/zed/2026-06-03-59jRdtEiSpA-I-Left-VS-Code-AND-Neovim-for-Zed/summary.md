# 저는 VS Code와 Neovim을 버리고 Zed로 갈아탔습니다

## 한 줄 요약

Chris Titus는 Zed를 VS Code 대체재가 아니라 Neovim과 VS Code를 섞은 에디터로 보고, 빠른 실행 속도, 훌륭한 Vim 바인딩, 커스텀 태스크, 에이전트 스레드, 간결한 Git 흐름 덕분에 두 에디터를 모두 버리고 Zed를 주력으로 쓴다고 말합니다.

## Neovim과 VS Code 사이의 에디터

- 1년 전 영상에서는 Zed를 VS Code 대체재로 썼지만, 지금은 Neovim과 VS Code 사이에서 태어난 에디터라고 생각이 바뀌었다고 합니다
- VS Code보다 훨씬 빨리 켜지고, AI 기능을 전부 끄는 토글이 있습니다. 본인은 코딩에서 AI를 많이 쓰지만 에이전트를 16개씩 돌리는 식은 아니라고 합니다
- VS Code에 Vim 플러그인을 깔았을 때는 느낌이 나빴지만, Zed의 Vim 바인딩은 가장 큰 충격일 정도로 훌륭하다고 합니다
- VS Code 기반 키맵을 가져온 뒤 그 위에 Vim 모드를 얹어 쓰고, 테마와 확장 기능 지원도 풍부합니다

## 레이아웃과 JSON 설정

- 스트리밍을 하느라 화면 공간이 좁아 왼쪽 패널을 모두 오른쪽으로 옮겼고, 덕분에 레이아웃이 깔끔하며 본인 머리가 화면을 가리지 않습니다
- 설정, 키맵, 태스크가 모두 JSON이라 Git 저장소에 백업해 Windows, Mac, Linux 사이에서 동기화합니다

## 커스텀 태스크로 만든 스크린샷 워크플로

- 아직 다른 사람이 다루는 걸 못 봤다며 `task.json`의 커스텀 태스크를 소개합니다
- 파일 이름을 입력하면 스크린샷이 마크다운 문서의 커서 아래에 바로 삽입됩니다. Wayland와 Xorg를 지원하고, 단축키로 지울 수도 있습니다
- 뒤에서는 웹에 최적화된 WEBP 파일을 만들어 넣습니다. 고해상도 이미지가 43KB 정도이고 PNG라면 4MB쯤 된다고 합니다

## 에이전트와 모델 선택

- GitHub에 큰 저장소가 있어 GitHub Copilot Pro를 무료로 받고 있으며, Gemini CLI, Cursor, Claude 에이전트 등 다른 에이전트도 설정할 수 있습니다
- Cursor는 웹 페이지 요소를 강조해 AI로 바꾸는 데는 좋지만 VS Code 포크라 무겁고 로딩이 느리다고 평가합니다. Zed는 닫았다 열어도 바로 켜집니다
- 모든 것에 단축키를 걸어 두었고, 키맵 파일은 텍스트로 쓰거나 GUI로 열어 설정할 수 있습니다
- 기본 모델도 설정 파일로 정합니다. VS Code의 자동 모드가 아무 모델이나 잡던 것과 달리, 코딩에는 GPT 5.2 Codex, 마크다운 작성에는 5.4처럼 정해 둘 수 있으며 영상 시점에는 5.2 Codex를 가장 좋아한다고 합니다
- 선택한 줄을 새 에이전트 스레드로 끌어오거나, 파일을 드래그 앤 드롭해 컨텍스트로 줄 수 있습니다

## 스레드로 프로젝트 오가기

- 병렬 처리도 되지만, 본인은 오픈 소스 프로젝트가 많아서 스레드로 에이전트를 돌렸던 Git 저장소로 정확히 돌아가는 용도로 쓴다고 합니다
- 에이전트가 허용을 요청하면 다른 작업을 하다 돌아와 승인할 수 있습니다
- 프로젝트는 왼쪽 위에 모여 있고 최근 프로젝트를 기억해 전환이 쉽습니다

## Git은 UI보다 CLI 위주

- Zed의 Git 흐름은 VS Code와 달라서 처음에는 라이브 방송에서 한두 시간 익혔지만, 지금은 VS Code보다 빨라졌다고 합니다
- 변경 추적, diff, 브랜치, 스태시, 워크트리를 볼 수 있습니다. 커밋은 대부분 CLI에서 하며, add, commit, push를 한 번에 하는 자작 명령 `lazy g`를 씁니다
- 영상에서는 병합 충돌을 해결한 뒤 푸시하는 과정을 보여 줍니다

## 테마와 마무리

- 대비가 필요하면 Gruvbox, 부드러운 쪽은 Dark Soft, 더 어둡게는 JetBrains Dark를 즐겨 쓰고, 사이버펑크나 블레이드 러너 같은 커뮤니티 테마도 많습니다. 테마 전환을 단축키에 묶을 수도 있습니다
- Vim과 Neovim 사용자가 VS Code나 Cursor를 곁에 두고 있다면 Zed가 둘 모두를 대체할 수 있다고 봅니다
- 반응이 좋으면 한 시간짜리 Zed 영상을 만들 수도 있으며, 지금은 Zed가 자신의 집이라고 말합니다
