### 에이전트 패널

**11:50** · 완벽하진 않았지만, 약간의 리뷰와 제때 잡아낸 아주 위험한 변경 덕에 몇 주 걸릴 일을 며칠로 줄였습니다. 솔직히 말해 비싼 VS Code 포크가 아니라 훨씬 훨씬 빠른 IDE에서 누리는 Cursor 경험입니다. 컨텍스트를 받아들이고, 문제를 반복하며, 권한을 설정합니다. 댓글로 토론해 봅시다. 저는 다른 이른바 에이전틱 IDE를 쓸 이유를 다시는 못 찾겠습니다.

**12:13** · 가격 이야기를 잠깐 해 보죠. 월 10달러에 무제한 예측이 포함되지만 일반 용도의 토큰 사용량은 꽤 제한적이고, 그걸 넘기면 API 정가에 10%가 붙습니다.

**12:26** · 지원하는 제공자 목록은 충분히 방대하고 그중에는 더 필요할 때 쓸 OpenRouter도 있습니다. Zed는 무료로 쓸 수 있습니다. 또 AI 기능을 전혀 쓰지 않고 빠른 코딩 에디터로만 쓸 수 있다는 점도 기억할 만합니다. Zed 블로그도 강력히 추천합니다. 새 기능을 발표하고, 독특한 옵션을 깊이 파고들고, 일반적인 생각도 공유합니다. 예상하듯 테마, 언어 지원, MCP 등 확장 기능 목록도 방대합니다. 자, 백만 달러짜리 질문입니다. 갈아탈 만큼 충분할까요? 글쎄요, 그렇기도 하고 아니기도 합니다.
