# Zed는 모든 IDE를 끝장낼 킬러일까?

## 한 줄 요약

발표자는 10년 넘게 쓴 Neovim을 버리지는 않겠지만, 설정 없이도 Vim 지원이 뛰어나고 에이전트 패널과 Warp 같은 터미널 AI까지 빠른 패키지에 담은 Zed는 계속 쓰겠다고 말합니다.

## Zed를 써 보게 된 계기

- Vim 애호가 토르스텐 볼의 "From Vim to Zed" 글을 읽고 한 번 써 봤지만 당시에는 매력을 못 느꼈다고 합니다
- 이후 Zed 측 초대를 받아 다시 써 보게 됐고, 이 영상은 Zed 후원을 받았습니다
- Zed는 Atom 팀이 Rust로 처음부터 만든 크로스 플랫폼 오픈 소스 에디터이며, 2025년 세쿼이아가 3,200만 달러를 투자했습니다

## 설정 없이도 쓸 만한 기본기

- CLI를 제공해 `kubectl edit` 같은 곳의 에디터로 지정할 수 있고, 커맨드 팔레트와 settings.json으로 대부분을 설정합니다
- 탭 전환 속도는 Neovim과 비교해 Zed가 아주 조금 빠른 느낌이었지만 둘 다 훌륭하다고 합니다
- Command J로 하단 독, Command B로 왼쪽 독을 토글해 UI를 비우고 집중할 수 있습니다
- Git 통합, AI 커밋 메시지 생성, 파일을 가로지르는 멀티커서가 기본으로 동작합니다. 다만 코드 이름 바꾸기는 주변 맥락을 쓰는 Neovim 쪽이 더 낫다고 봅니다

## Neovim 사용자에게 집 같은 Vim 모드

- 플러그인도 설정 이식도 없이 텍스트 오브젝트, 진단 이동, 매크로, 점프 리스트, Ctrl W 창 관리가 기대한 대로 동작해 거의 집처럼 편하다고 합니다. 100% Vim 대체재는 아니지만 충분히 가깝다는 평가입니다
- 아쉬운 점은 Telescope나 FZF 같은 퍼지 파인더가 없다는 것입니다. Command P 파일 검색이 대신하며, 퍼지 파인더는 열린 이슈로 남아 있습니다
- `jj`, `jk` 매핑이 안 먹혀 헤맸는데, Zed가 공백을 구분자로 쓰기 때문에 키 사이에 공백을 넣어야 했습니다
- 키맵 이식은 Gemini에게 Neovim 설정을 주고 Zed용 키맵을 만들게 했고, 대부분 이미 있는 기본값이었다고 합니다

## AI 기능과 협업, 디버깅, 터미널

- 예측은 Hugging Face에 공개된 오픈 소스 모델 Zeta가 맡습니다. 속도가 빠르고, 베타인 동안 무료입니다
- 협업 독으로 라이브 채널, 통화, 화면 공유, 채팅을 쓸 수 있고, 프록시나 자체 Zed 서버도 설정할 수 있습니다
- 디버거는 DAP를 지원하며 다른 IDE와 비슷하게 동작합니다
- 터미널에는 인라인 AI 도움이 있어 자연어를 명령어로 바꿔 줍니다. 발표자는 Warp를 떠올리게 한다고 합니다

## 에이전트 패널과 가격

- 에이전트 패널은 LLM과 상호작용하는 주된 관문이며, 직접 가져온 키와 Claude CLI, Gemini, Codex 같은 터미널 에이전트를 지원합니다
- 발표자는 Codex와 Gemini CLI로 프로덕션 기능을 출시했고, 위험한 변경을 제때 잡아내는 리뷰를 거쳐 몇 주 걸릴 일을 며칠로 줄였다고 합니다. 비싼 VS Code 포크가 아닌 훨씬 빠른 IDE에서 누리는 Cursor 경험이라며, 다른 에이전틱 IDE를 쓸 이유를 못 찾겠다고 말합니다
- 요금은 월 10달러에 무제한 예측이 포함되고 일반 용도의 토큰은 제한적이며, 초과하면 API 정가에 10%가 붙습니다. OpenRouter 등 제공자가 다양하고, AI 없이 에디터로만 써도 됩니다

## 결론: 갈아타지는 않고 함께 씁니다

- Neovim은 그대로 쓰되, 에이전트 패널과 Warp 같은 터미널, Neovim에 견줄 Vim 지원을 한 번에 갖춘 Zed는 계속 쓰겠다고 합니다
- 터미널을 더 좋아한다면 자신이 가장 좋아하는 터미널 에이전트 Open Code를 추천하며, 유연한 과금 덕에 둘을 함께 쓸 수 있다고 합니다
