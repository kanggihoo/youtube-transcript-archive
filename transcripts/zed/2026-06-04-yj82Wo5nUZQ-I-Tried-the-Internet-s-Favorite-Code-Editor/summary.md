# I Tried the Internet's Favorite Code Editor

## 한 줄 요약

협찬을 받았지만 솔직한 후기를 약속한 SleepyCatHey는 Zed를 깔끔한 UI, 자유로운 커스터마이징, 끌 수 있는 AI가 장점인 미니멀 에디터로 평가하고, 초보자에게는 어렵고 확장 기능이 부족하다는 점을 단점으로 꼽습니다.

## 협찬과 솔직한 후기

- 구독자 요청으로 만든 영상이며, Zed의 협찬을 받았지만 내용은 자유롭게 만들고 솔직한 의견을 말해도 된다고 밝힙니다
- 기능 나열 대신 UI, 커스터마이징 정도, 개발 생활을 얼마나 편하게 하는지를 살펴봅니다

## 설치와 첫인상

- Zed는 사람과 AI의 협업과 속도를 위한 미니멀한 오픈 소스 코드 에디터이며 AI가 내장되어 있습니다
- 환영 화면에서 테마와 다른 에디터의 키맵, AI, Vim 모드를 고를 수 있습니다. GitHub Copilot은 바로 설치되었고 속도가 빠르다고 느낍니다
- 설정 파일을 열자 UI가 이미 원하던 모습이었고, 직접 VS Code를 이렇게 꾸미는 영상을 만들어야 했다고 말합니다

## 화면 구성과 주요 기능

- 파일 메뉴를 숨기고 스레드 메뉴(AI 채팅 스레드)를 오른쪽으로 옮길 수 있으며, 여러 스레드를 동시에 쓸 수 있습니다
- 미니맵, 인라인 진단, Vim 모드, AI 제공자와 모델 선택, 로컬 모델 지원이 있습니다
- 영상 편집 중 나온 터미널 스레드 기능으로 Claude Code 같은 CLI 코딩 에이전트를 Zed 안에서 스레드별로 정리해 쓸 수 있습니다
- 프로젝트 검색으로 같은 단어가 든 줄을 모두 찾아 한 번에 바꿀 수 있고, 내장 Git 패널과 협업 패널도 있습니다

## 설정에서 줄이고 꾸미기

- 외관에서는 동적/정적 테마 모드를 고르고, 에디터뿐 아니라 앱 전체의 글꼴, 크기, 두께를 바꿀 수 있습니다
- 브레드크럼과 퀵 액션을 끌 수 있고, Prettier가 내장되어 있으며, Vim 모드는 그대로 둡니다
- 창과 레이아웃, 패널 설정에서 프로젝트 패널, 언어 버튼, 커서 위치 버튼 등 필요 없는 요소를 없앨 수 있습니다
- 협업 기능은 디스코드와 비슷하다고 보지만 같이 할 사람이 없어 쓰지 않습니다

## AI를 한 번에 끌 수 있다

- 클릭 한 번으로 AI 기능이 모두 사라지며, 새 언어를 배울 때 AI가 방해하지 않아 유용하다고 봅니다
- AI 에이전트는 빠르지만 결국 Copilot이라 특별하지 않다고 봅니다. 바이브 코딩에는 좋고 프로필을 만들어 쓸 수도 있습니다

## 확장 기능과 최종 평가

- 확장 기능으로 테마와 아이콘 팩(Mocha)을 설치하자 테마가 동적으로 바뀌고 익숙한 환경이 됩니다
- 장점은 필요한 일만 하는 미니멀함, 원하는 AI 사용, 자주 업데이트를 공유하는 개발팀, AI 끄기, 자유로운 커스터마이징입니다
- 단점은 고급 개발자용이라 완전한 초보에게는 어려울 수 있다는 점과, 쓰는 Manim 확장이 없을 만큼 확장 기능이 아직 제한적이라는 점입니다. 시간이 지나면 늘어날 것으로 봅니다
- 본인에게 필요한 것이 일부 빠져 있어 주력으로 쓰기는 어렵지만, 새 코딩 언어를 배우는 용도로는 좋을 것 같다고 말합니다
