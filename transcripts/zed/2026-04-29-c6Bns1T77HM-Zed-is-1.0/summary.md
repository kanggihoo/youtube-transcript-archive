# Zed 1.0

## 한 줄 요약

Zed Industries는 브라우저 기반이 아닌 100% Rust와 자체 UI 프레임워크 GPUI로 처음부터 만든 코드 에디터 Zed가 1.0에 이르렀고, 속도와 Git·멀티 버퍼·원격 개발, 병렬 에이전트 AI 기능을 갖췄다고 소개합니다.

## 브라우저 위가 아닌 Rust와 GPUI

- 대부분의 에디터는 웹 브라우저 위에 만들어지지만, Zed는 100% Rust로 작성했고 직접 만든 UI 프레임워크 GPUI 위에 지었습니다
- 모든 프레임을 GPU로 가속하며, 이 기반을 만드는 데 수년이 걸렸다고 합니다
- 스택의 모든 계층을 직접 소유하기 때문에 대부분의 도구가 물리적으로 따라올 수 없는 속도로 반응한다고 주장합니다

## 실제 업무를 맡길 수 있는 기능

- 크기에 상관없이 diff를 검토하고 스테이징·커밋까지 에디터 안에서 할 수 있는 Git 도구
- 여러 파일을 하나의 화면에서 다루는 멀티 버퍼 편집
- 최상급 원격 개발 지원
- 영상에 나온 사용자는 속도에 감탄했고, 멀티 버퍼와 멀티 커서를 가장 좋아하는 부분으로 꼽습니다

## 에이전트가 일하는 에디터

- 에이전트는 코드베이스 전반에서 병렬로 실행되며 서브 에이전트를 생성할 수 있고, 에디트 예측은 입력하는 즉시 나타납니다
- Zed 자체 에이전트를 포함한 여러 에이전트를 나란히 실행할 수 있습니다
- 자신의 API 키를 쓰거나 Zed가 호스팅하는 최신 모델 접속을 쓸 수 있어 선택권은 사용자에게 있습니다
- 다른 사용자는 Claude Code와 Codex CLI를 오가며 쓰는데 하나의 통합 인터페이스에서 할 수 있어 좋다고 말합니다

## 사용자가 만드는 에디터

- Zed는 사용자가 만들고 사용자를 위해 존재하며, 사용자들이 기능을 내놓고 치명적인 버그를 고치고 이슈를 분류하며 매주 기반을 발전시킨다고 합니다
- 영상은 Zed를 내려받아 써 보라는 말로 끝납니다
