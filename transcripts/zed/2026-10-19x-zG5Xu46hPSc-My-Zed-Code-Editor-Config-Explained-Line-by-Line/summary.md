# 내 Zed 코드 에디터 설정 한 줄씩 설명

## 한 줄 요약

15년 경력 개발자 닉은 새로 설치한 Zed를 자기 취향에 맞게 바꾸는 설정(테마, 폰트, 아이콘, 키맵, 들여쓰기 등)을 JSON 설정 파일의 줄 단위로 보여 주고, 나머지 옵션은 공식 문서나 기본 설정 파일 검색으로 찾으라고 말합니다.

## 테마와 아이콘

- 터미널, Vim, 다른 에디터까지 가능한 모든 곳에서 Everforest 테마를 쓰며, Zed 기본 테마에 들어 있어 지정만 하면 됩니다
- zed themes dot com에는 100개가 넘는 테마가 있고, 마음에 드는 테마를 수정하거나 처음부터 새로 만들 수도 있습니다
- 파일 아이콘은 색이 있는 쪽을 좋아해서 Zed에 기본 포함된 Catppuccin Macchiato 아이콘 테마를 씁니다

## 폰트: 버퍼와 UI를 구분하기

- buffer font family·size는 코드에만, UI font family·size는 에디터 인터페이스에만 영향을 줍니다
- 코드에는 Nerd Fonts 계열의 Iosevka를 씁니다. 가로 글자 밀도가 높아 한 줄에 많은 텍스트가 들어갑니다. 처음엔 좁고 낯설었지만 며칠 뒤 한눈에 훑어보기 쉬워져 터미널에서도 씁니다
- 인터페이스는 기본 시스템 폰트로 두어 Zed가 macOS 스타일과 어우러지게 합니다
- buffer line height는 1.4(기본보다 줄 간격 40% 증가), 리거처는 buffer font features로 끄고, buffer font weight는 100(가장 얇음)~900(가장 굵음) 중 400이 보통인데 300으로 둡니다. 폰트가 가로로 눌려 있어서 더 가볍게 보이게 하려는 것입니다

## 키맵과 Vim 모드

- base keymap은 다른 에디터의 단축키 배치를 켜고, Vim 모드는 Vim 스타일 명령과 모달 편집을 켭니다. 서로 보완하지 않으므로 한 번에 하나만 씁니다
- 본인은 오래 써 온 Sublime Text 키맵을 쓰고, 두 설정을 다 적어 둔 채 하나를 주석 처리해 기분에 따라 바꿉니다

## 화면을 덜어 내는 설정

- 툴바는 브레드크럼과 빠른 작업 표시를 둘 다 끄면 사라집니다. 에디터 창을 코드로 채우려는 목적입니다
- project panel entry spacing을 standard로 두면 파일 트리에 더 많은 정보가 보이고, 너무 빽빽하면 comfortable로 바꿉니다
- 탭에는 tab file icon으로 아이콘을 넣습니다
- inline blame은 거의 쓰지 않는데 기본으로 항상 보이고 터미널에서 이미 쓰므로 끕니다. 현재 줄 하이라이트도 집중만 흐트러뜨린다고 보고 끕니다

## 포맷팅과 들여쓰기

- 저장 시 자동 포맷팅은 항상 꺼서 파일이 의도하지 않은 변경 없이 저장되게 합니다
- tab width는 4, hard tab을 켜서 공백 대신 탭 문자를 씁니다. 자바스크립트 세계의 두 칸 들여쓰기는 덜 눈에 띄어 싫다고 하며, 탭 대 스페이스 논쟁은 원하지 않는다고 덧붙입니다

## 다른 설정 찾는 법

- Zed 공식 웹사이트의 문서 섹션에 모든 옵션이 설명되어 있습니다
- 빨리 찾으려면 기본 설정 파일을 열어 키워드로 검색하고, 해당 설정을 내 설정으로 복사해 값을 바꾸면 됩니다
