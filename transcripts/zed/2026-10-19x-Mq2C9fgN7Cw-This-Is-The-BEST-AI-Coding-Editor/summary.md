# 이것이 최고의 AI 코딩 에디터입니다

## 한 줄 요약

Mehul Mohan은 Rust로 만든 빠른 에디터 Zed가 특정 AI 업체에 묶이지 않고 여러 에이전트를 한 화면에서 돌릴 수 있으며, 클릭 한 번으로 워크트리를 만들어 병렬 작업을 쉽게 해 주기 때문에 자신이 써 본 최고의 에디터라고 말합니다. 이 영상은 Zed의 후원을 받았다고 밝힙니다.

## 빠르고 가벼운 기본기

- Zed는 성능과 반응 속도가 뛰어나고, 파일 열기와 구문 강조가 즉시 이뤄집니다
- command shift P(Windows는 control shift P) 하나로 설정, 확장 등 거의 모든 것에 접근합니다
- Python, Rust, TypeScript 같은 인기 언어는 내장이고, 나머지는 확장으로 추가합니다. PHP 파일을 만들면 권장 확장 설치를 제안합니다
- 로그인 없이도 쓸 수 있고, 기본 키맵을 VS Code, Atom, JetBrains 등으로 바꿀 수 있습니다
- Git blame이 기본 내장이고, 내장 디버거와 음성 통화 및 실시간 공동 편집(무료 계정 필요)도 있습니다

## 취향에 맞게 꾸미기

- Material Icons 아이콘 테마, One Dark Pro Max 에디터 테마, 주석을 색으로 강조하는 Comments Highlighter를 씁니다. 확장은 다운로드가 수십만 회 이상인 것을 선호합니다
- 설정은 settings.json과 설정 UI 두 가지이며, 언어 서버 기반 제안이 나옵니다
- 기본값은 파일 사이드바가 오른쪽이고 AI 에이전트 독이 왼쪽입니다. 직접 코딩하는 일이 줄고 코드 리뷰가 주가 되었으니 사이드바를 왼쪽으로 옮겨 쓴다고 합니다

## 어떤 AI든 붙이는 세 가지 방식

- ACP(에이전트 클라이언트 프로토콜): 레지스트리에서 Claude, Codex, open code, Kilo, Gemini, Factory Droid, Cursor 등을 골라 Zed 안에서 씁니다. open code와 open router로 Kimi K2.7 code를 돌리는 예를 보여 줍니다
- LLM 키: open router, Anthropic 등의 키를 주면 Zed 자체 하니스가 그 모델을 씁니다. Zed 자체 모델은 14일 체험판이 있고, ChatGPT 구독과 Ollama 로컬 모델도 연결됩니다
- 터미널 에이전트: 터미널에서 Claude, Codex, Pi, amp 등을 실행하고 Zed 기능 일부를 받습니다
- 에이전트 스레드를 여러 개 만들어 섞어 쓸 수 있고, 끝난 스레드는 보관 처리해 정리합니다

## Claude 구독이면 터미널 스레드로

- 발표자는 6월 15일부터 ACP를 통한 Claude 트래픽이 요금제에 포함된 크레딧 한도에서 차감된다고 말합니다
- 따라서 Claude Max 같은 구독이 있다면 ACP 에이전트 스레드 대신 터미널 스레드를 써야 구독 혜택을 받는다고 합니다
- 터미널 스레드에서도 제목 자동 갱신, 파일 링크 클릭으로 워크스페이스에서 열기 같은 연동이 됩니다

## ACP 에이전트의 장점: 커서 따라가기와 diff 리뷰

- ACP 에이전트는 follow 기능으로 에이전트가 파일을 찾고 코드를 고치는 모습을 커서를 따라 실시간으로 볼 수 있습니다. 터미널 에이전트에서는 되지 않습니다
- Git 브랜치 diff 화면에서 변경을 리뷰하고 옆에서 AI에게 리뷰를 시킬 수도 있습니다. 발표자는 AI가 위험한 코드나 나쁜 관행을 내보내지 않게 확인하는 것이 사람에게 남은 일이라고 봅니다

## 클릭 한 번으로 워크트리, 병렬 에이전트

- 새 워크트리를 누르면 이름이나 경로를 묻지 않고 1초 안에 루트 디렉터리 아래 워크트리 폴더에 만들어 줍니다
- 예시로 Kysely를 Prisma, drizzle, 날 SQL로 바꾸는 세 작업을 각각 다른 워크트리에서 Claude, Codex 에이전트에게 동시에 맡깁니다
- 워크트리가 어렵고 번거롭다는 평가에 동의했었지만 Zed에서는 식은 죽 먹기라고 합니다
- 워크트리에는 git이 무시하는 node 파일이 없어 pnpm install을 따로 해야 합니다. 직접 하거나 에이전트가 하게 둡니다
- 끝나면 워크트리를 휴지통으로 보내거나 삭제하면 자동 동기화되고, 브랜치 전환과 스태시도 UI에서 됩니다
