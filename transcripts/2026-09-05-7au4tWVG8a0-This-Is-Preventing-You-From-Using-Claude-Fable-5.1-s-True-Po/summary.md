# This Is Preventing You From Using Claude Fable 5.1's True Potential

## 한 줄 요약

Fable 5.1은 복잡한 대규모 작업을 도중에 멈추지 않고 끝까지 완주하는 능력이 뛰어나고 캐시 읽기 비용이 대폭 절감되었으나, 과도한 출력 생성·무통보 가드레일 다운그레이드·환각 증가 등의 특성이 있으므로 low effort 설정, 구버전 지침 제거, 무인 자율 실행 권한 부여 등 맞춤형 프롬프트 전략을 적용해야 한다.

## Fable 5.1 잠재력을 극대화하는 7가지 프롬프트 및 운영 팁

### 1. Effort 설정을 낮추기 (Low Effort 권장)
- **과도한 심사숙고 방지**: Code Rabbit 벤치마크에서 low effort가 문제 탐지율 61%(high effort 57.1%)를 기록하며 약 3분 더 빠르게 완료함
- 복잡한 기능 구현 시에도 high effort는 한 부분에서 맴돌 위험이 크므로, 기본 설정을 low effort로 두고 명확한 필요가 있을 때만 상향 조정

### 2. 이전 모델용 지침(Instructions) 제거
- 구버전의 한계를 우회하려고 작성했던 지침들이 Claude.md 등에 남아 있으면 불필요한 제약이 되어 토큰을 낭비하고 오작동을 유발함
- `Claude API prompt audit` 명령어를 실행해 레거시 지침을 식별하고 불필요한 규칙을 정리

### 3. 무인 자율 실행 권한 부여 (Let it run unattended)
- 장기 작업 중 이미 초기 요청에 포함된 단계임에도 사용자의 확인을 기다리며 대기 상태에 빠지는 현상 방지
- 프롬프트에 *"지켜보는 사람이 없으니 되돌릴 수 있는(undoable) 작업이라면 기존 요청에 포함된 모든 단계를 멈추지 말고 계속 진행하라"*고 명시

### 4. 건드리지 말아야 할 대상 명시 (What to leave alone)
- 요청한 범위 외의 주변 코드나 테스트 파일을 자의적으로 수정하거나 확장하는 경향을 차단
- 요청한 기능 외에는 수정하지 말 것과, 추가로 발견한 문제는 작업 중 임의로 수정하지 말고 완료 후 목록으로 보고하도록 지시

### 5. 전체 재작성 방지 및 부분 수정 강제 (Edit, don't rewrite)
- 일부분만 수정해도 되는 파일 전체를 통째로 다시 작성하여 출력 토큰을 낭비하고 제한을 소진하는 문제 방지
- *"작은 수정으로 동일한 결과를 낼 수 있다면 전체를 재작성하지 말고 해당 부분만 편집(edit)하라"*고 명시

### 6. 기교 부린 문체 배제 (Cut the mannered prose)
- 직설적 표현 대신 현학적인 미사여구나 은유, 길어지는 만연체 문장을 방지
- 프롬프트에 *"기교 부린 문체(mannered prose)를 일체 사용하지 말고 간결하고 직설적으로 서술하라"*고 지정하여 리서치 및 문서 작성의 명확성 확보

### 7. 작은 단계가 아닌 큰 단위 작업 위임 (Give it big tasks)
- 기능을 여러 개의 잘게 쪼갠 프롬프트로 나누어 주는 대신, 전체 기능 명세를 한 번에 전달하고 목표 결과를 명확히 제시
- Fable 5.1은 작업을 중단 없이 끝까지 밀고 나가는 능력이 탁월하므로, 대형 작업을 통째로 맡길 때 생산성과 비용 절감 효과가 극대화됨
