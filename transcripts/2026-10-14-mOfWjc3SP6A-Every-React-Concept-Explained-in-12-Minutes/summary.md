# Every React Concept Explained in 12 Minutes

## 한 줄 요약

컴포넌트와 JSX부터 훅, context, 포털, suspense, 서버 컴포넌트, 하이드레이션까지 React 개념 수십 개를 쇼핑몰 예시 하나로 12분에 훑는 로드맵 영상으로, 외우기보다 전체 지도를 보여 주는 것이 목적입니다.

## UI를 조립하는 법

- **컴포넌트**는 보여 줄 것을 반환하는 함수이고 여러 번 재사용되며 컴포넌트 트리를 이룹니다. JSX는 자바스크립트 안에서 인터페이스를 기술하는 문법이고 중괄호로 값을 넣습니다
- 컴포넌트는 요소 하나만 반환하므로 여러 요소는 프래그먼트로 묶습니다
- **props**는 부모가 자식에게 주는 입력이고, **children**으로 UI 조각 자체를 넘기는 것이 조합(composition)입니다
- 조건부 렌더링은 평범한 자바스크립트 조건(삼항 연산자 등)으로 하고, 리스트는 map으로 만들며 안정적인 key(보통 데이터 ID)가 필요합니다

## state와 렌더링의 원리

- state는 컴포넌트가 기억하는 값이고 useState로 현재 값과 갱신 함수를 얻습니다. 값이 바뀌면 React가 컴포넌트를 다시 호출(렌더링)하고, 결과를 이전과 비교해 DOM에서 바뀐 부분만 갱신합니다. 이것이 선언적 UI입니다
- 가상 DOM은 메모리 속 기술, 재조정은 무엇이 바뀌었는지 알아내는 과정, 커밋은 DOM에 반영되는 시점입니다
- state 갱신은 즉시 일어나지 않아 바로 다음 줄에서는 이전 값이 보입니다. 새 변수를 써서 우회합니다
- 컴포넌트는 순수해야 합니다. 렌더링 결과에 math.random이나 date.now를 직접 쓰면 입력이 같아도 결과가 달라질 수 있습니다
- 폼은 onChange로 입력값을 state에 저장해 목록을 거르는 식으로 다루고, 두 컴포넌트가 같은 값을 쓰면 가장 가까운 공통 부모로 state를 끌어올립니다

## 훅과 사이드 이펙트

- 같은 state 로직이 반복되면 `use`로 시작하는 커스텀 훅(예: useCounter)으로 뽑아 한 곳에서 고칩니다
- 컴포넌트는 마운트, 업데이트, 언마운트의 생명주기를 가집니다. 타이머나 데이터 가져오기 같은 사이드 이펙트는 렌더링 코드가 아니라 useEffect에서 렌더링 후에 실행합니다
- 의존성 배열이 비어 있으면 마운트 때만 돌고, 값을 넣으면 그 값이 바뀔 때 다시 돕니다. 이펙트가 반환하는 클린업 함수는 언마운트 때와 다시 실행되기 전에 호출되어 타이머나 연결을 정리합니다
- useRef는 DOM 요소에 접근하거나, 바뀌어도 리렌더링을 일으키지 않아야 하는 값을 보관할 때 씁니다. 화면에 보이는 값은 state에 둡니다

## 멀리 있는 데이터와 큰 상태 다루기

- 여러 단계를 거쳐 props를 넘기는 prop 드릴링은 context(provider와 useContext)로 해결하며 트리 일부에만 적용할 수도 있습니다
- 갱신 로직이 복잡해지면 useReducer로 action과 리듀서에 모으고, state와 dispatch를 context로 공유합니다
- 포털(createPortal)은 자식을 DOM의 다른 곳에 렌더링해 잘림 문제를 피하면서도 같은 React 트리에 속해 같은 context를 씁니다

## 로딩, 성능, 서버

- suspense는 로딩 중 대체 UI를 보여 주지만 lazy나 use로 읽는 프로미스처럼 suspense를 지원하는 로딩이어야 하고, useEffect 안의 fetch는 자동으로 작동시키지 않습니다. use API는 렌더링 중 context나 프로미스를 읽고 조건부로 호출할 수 있습니다
- 메모이제이션은 React Compiler가 켜져 있으면 대부분 자동이고, 아니면 useMemo로 수동 처리합니다. 폼은 action prop에 함수를 넘겨 제출을 처리합니다
- 서버 컴포넌트는 Next.js 같은 프레임워크에서 컴포넌트 코드를 브라우저로 보내지 않고 서버에서 데이터를 보여 주어 JS를 줄입니다. 인터랙티브한 부분은 클라이언트 컴포넌트이고, 서버가 만든 HTML에 React 동작을 연결하는 것이 하이드레이션입니다. 첫 브라우저 렌더링이 서버 HTML과 일치하도록 같은 초기 데이터를 쓰고 렌더링 중 랜덤 값을 피해야 합니다
- 영상 끝에서 발표자는 다 외울 필요 없고 로드맵으로 보라고 하며 자신의 유료 강의를 안내합니다
