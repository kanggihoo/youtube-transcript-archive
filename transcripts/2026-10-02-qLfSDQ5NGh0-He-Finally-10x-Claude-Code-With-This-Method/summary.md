# He Finally 10x Claude Code With This Method

## 한 줄 요약

Karpathy의 Auto Researcher 방식(수정 가능 파일 하나, 잠긴 점수 파일, 지침 파일 `program.md`)을 앱 개발에 옮긴 루프 설정 소개. 루프가 놓치는 "에이전트의 반복되는 습관"은 첫 루프의 결과를 읽고 지침을 다시 쓰는 두 번째 루프(`auto loop`)로 고칩니다.

## Karpathy 방식: 한 파일, 잠긴 채점, 평이한 지침

- 에이전트는 모델을 학습시키는 **파일 하나만** 수정합니다. 라운드마다 변경 하나를 가하고 몇 분 학습시킵니다
- 별도의 점수 파일이 채점해 좋아지면 유지, 같거나 나빠지면 되돌립니다. **에이전트는 점수 파일을 건드릴 수 없습니다** — 건드리면 모델 대신 기준을 쉽게 만들 수 있기 때문입니다
- `program.md`가 각 라운드 진행법을 평이한 영어로 알려줍니다
- 이틀간 실험 700번, 학습을 빠르게 하는 변경 20개. Shopify CEO는 자는 동안 37번을 돌려 모델이 19% 좋아졌다고 합니다

## 루프가 값어치 있는 작업의 조건 네 가지

잘못된 작업에 쓰면 토큰만 낭비합니다.

1. 작업을 **자주 반복**한다 (한 번이면 좋은 프롬프트 하나가 낫습니다)
2. **사용량 한도**가 버틴다 (실패한 라운드도 토큰을 씁니다. 월 20달러 요금제에서 긴 루프는 한도에 먼저 닿습니다)
3. 명확한 **점수로 검사**할 수 있다 (앱에서는 기능을 실행해 확인하는 작은 코드)
4. 에이전트가 만든 것을 **실행해 무엇이 깨지는지** 볼 수 있다

발표자 팀은 앱 전체를 루프 한 번에 맡기지 않고, 한 번에 기능 하나나 검사로 확인되는 단순 버전에만 씁니다.

## 설정: 스킬과 에이전트 구성

- **project context 스킬** — 앱이 하는 일, 페이지, 관례, 피할 것을 담은 기억 저장소. 파일 대신 스킬로 두는 이유는 짧은 설명만 항상 컨텍스트에 남고 전체는 필요할 때만 불러오기 때문
- **build 스킬** — 루프 전체를 구동. 먼저 `write checks` 스킬로 **기능을 만들기 전에 검사부터 작성**
- 검사를 쉬운 말로 나열하고 사용자가 보완한 뒤 `approve checks`가 **잠긴 폴더로 옮기고**, Claude Code 설정 규칙이 그 폴더 수정을 막으며, 커밋까지 해 이중으로 보호
- 기능은 **feature builder 에이전트**가 매번 새 컨텍스트로 구현. 라운드 결과는 파일에 저장, 고정 규칙과 작업 방식은 `program.md`에 둠

## 실행 결과: 점수에 안 보이던 것까지 잡았다

식당 사이트의 포장 주문 기능에서 검사 11개(이메일 형식 검사 추가)가 첫 라운드에 전부 통과했고 약 6분이 걸렸습니다. 검사는 주문 규칙만 테스트했지만 루프는 **주문 양식이 빠진 것을 스스로 알아채** 만들어 연결한 뒤 완료로 표시했습니다.

## 남은 문제와 해법: 습관을 고치는 두 번째 루프

기능마다 새 에이전트와 같은 지침으로 시작하므로 **한 라운드의 실수가 다음 기능에서 반복**됩니다. `auto loop` 스킬이 모든 라운드의 results 파일(유지/되돌림, 시도 내용, 계속 실패한 검사)을 읽어 반복되는 문제를 습관으로 기록하고, `program.md`의 작업 방식 부분을 다시 씁니다. **검사는 수정할 수 없습니다.** 수정할 수 있다면 습관은 안 고친 채 통과만 쉬워지기 때문입니다.

build 스킬은 한 번 통과시킬 뿐 배운 것이 다음 기능으로 이어지지 않는 반면, auto loop는 기능이 끝날 때마다 지침을 갱신합니다.

## 협업 기능 예시에서 생긴 습관 두 가지

- 공유 DB가 검사 10개를 통과했지만 앱은 아무것도 저장하지 않았음 → **검사 통과와 같은 라운드에 기능을 앱에 연결**
- 멘션이 통과했지만 앱의 오래된 부분은 `@`를 예전 방식으로 읽음 → **이미 그 일을 하는 모든 곳을 찾아 새 규칙을 따르게 함**

이후 기능은 화면이 이미 연결된 채로 나왔고, 검사는 실제로 실수를 걸러냈습니다(멘션을 깨뜨린 라운드는 되돌려지고, 3명이 33씩이라 합이 99가 되는 분배 오류는 세 번째 라운드에서 수정).

발표 중 스폰서 Upstash Box(에이전트마다 클라우드 샌드박스를 주는 서비스) 소개가 끼어 있으며, 스킬 전체는 발표 채널의 유료 커뮤니티에서 제공한다고 안내합니다.
