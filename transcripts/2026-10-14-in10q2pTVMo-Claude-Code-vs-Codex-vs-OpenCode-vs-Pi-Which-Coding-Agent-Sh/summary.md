# Claude Code vs Codex vs OpenCode vs Pi: Which Coding Agent Should You Use in 2026?

## 한 줄 요약

터미널 코딩 에이전트 넷을 일곱 라운드로 비교해 OpenCode를 종합 1위로 꼽았고, 샌드박스와 승인이 중요하면 Claude Code, 돈을 낸다면 Codex, 직접 환경을 짜고 싶다면 Pi를 추천합니다.

## 비용 구조

- Claude Code는 Pro 월 17~20달러, Max 월 100달러부터이며 5시간 단위 갱신 구간과 주간 한도가 있습니다. 기업 사용은 활성 개발자 하루 약 13달러 수준으로 제시됩니다
- Codex는 ChatGPT Pro 요금제(월 100, 200, 500달러)와 함께 오고, 초과분은 크레딧으로 사며 빠른 모드는 크레딧을 더 빨리 씁니다
- OpenCode는 무료에 MIT 라이선스이고, 선택 사항인 Go 요금제는 월 10달러와 40달러입니다. 사이트의 "100% 무료" 표기와 구독 요구가 어긋난다는 불만이 있습니다
- Pi는 도구 요금이 없고 제공자 키나 OAuth로 직접 결제하며, 하단에 누적 비용을 보여 줍니다. 이미 모델에 돈을 내는 경우가 아니면 무료라고 부르기 어렵다고 합니다
- 이 라운드는 OpenCode가 가져갑니다

## 연결할 수 있는 모델

- Claude Code는 외부 제공자를 받지만 유료 요금제는 Opus 5.5 중심으로 조율되어 있습니다
- Codex는 한 번 로그인으로 CLI, 편집기, 웹이 같은 요금제를 쓰고, 모델은 API 키를 따라갑니다
- OpenCode는 키가 있는 어떤 제공자든 쓰고, 목록의 무료 모델은 기간 한정이며 무료 기간에는 데이터가 개선에 쓰일 수 있습니다
- Pi는 15개 이상 제공자, 세션 중 모델 전환, 사용자 정의 제공자를 지원하며 컨텍스트 창은 기본 128K입니다
- 이 라운드는 Pi가 가져갑니다

## 안전장치

- Claude Code는 수동 모드에서 읽기 전용으로 시작해 수정, 테스트, 명령 실행 전에 허락을 구하고, Bash 샌드박스와 프롬프트 인젝션 보호를 문서화합니다
- Codex는 샌드박스(접근 범위)와 승인(멈출 시점) 두 단계이며, 자격 증명을 기본으로 평문 파일에 저장합니다
- OpenCode는 반복 도구 요청과 프로젝트 밖 경로를 기본으로 막고, 명령 패턴별 허용/질문/차단을 지원하지만 샌드박스 요청은 2025년 8월부터 열려 있습니다
- Pi는 권한 시스템이 없고 격리 방법 네 가지를 문서로만 안내합니다
- 이 라운드는 Claude Code가 가져갑니다

## 벤치마크는 하네스 포함 점수

- Terminal Bench 2.0에서 Codex(GPT 5.5)가 82.2%로 명령줄 에이전트 1위이고, Artificial Analysis 지수에서도 78.7점으로 선두입니다
- 이런 점수는 모델에 하네스를 더한 값이라 둘러싼 루프에 따라 10점 이상 달라질 수 있고, 지수 34개 행 중 20개가 Codex 변형이라 선두에는 표본 편향도 섞여 있습니다
- Anthropic 에이전트의 지수 최고 기록은 약 71.1이며 과제당 1.26달러입니다. 호스트 모델을 고정하면 OpenCode 65점 대 Claude Code 57점입니다
- Pi는 두 점수판에 나오지 않고, 과제당 비용은 조합에 따라 27센트에서 11.80달러까지 벌어집니다
- 이 라운드는 Codex가 가져갑니다

## 둘째 날의 프로젝트 상태

- Codex는 릴리스 1,221개, 열린 이슈 22,052개(버그 18,462개)이며 독립 실행형 Windows 설치 프로그램이 없습니다
- Claude Code는 릴리스 241개, 열린 이슈 14,005개(버그 9,496개)이며 Agents.md 지원 요청과 터미널 깜박임, 10GB 데스크톱 번들 문제가 남아 있습니다
- OpenCode는 릴리스 878개, 열린 이슈 3,322개이고 버그 라벨은 35개뿐이라 숫자를 조심해서 읽어야 합니다
- Pi는 열린 이슈 239개로 짧지만 긴 세션에서 CPU가 뜨겁고 신규 기여자 이슈를 자동으로 닫습니다
- 이 라운드는 OpenCode가 가져갑니다

## 확장과 설치

- Claude Code는 마켓플레이스 플러그인, 스킬, 서브 에이전트, 훅, MCP를 지원하며 설치 전에 컨텍스트 비용 추정을 보여 줍니다. 단 플러그인은 내 권한으로 실행되므로 신뢰 결정입니다
- Codex는 설정 파일 기반 MCP 연결이고 확장성은 제3자 평가에서 낮음~중간입니다. OpenCode는 에이전트별, 명령 패턴별 권한과 설정 파일 기반 플러그인을 쓰지만 공식 편집기 확장과 앱 스토어가 없습니다
- Pi의 확장은 사전 빌드 없는 TypeScript 모듈이고 JSON과 RPC를 지원하며 Pi와 같은 OS 권한으로 실행됩니다. 이 라운드는 Pi가 가져갑니다
- 설치는 Claude Code 네이티브 방식이 자동 업데이트되고, Codex는 되돌리기 명령이 사라졌으며, Pi는 Node 22.19 이상이 필요합니다. OpenCode는 여러 패키지 관리자로 설치되지만 Windows는 WSL을 권장합니다. 이 라운드는 OpenCode가 가져갑니다

## 결론과 추천

- 점수판은 OpenCode 3, Pi 2, 나머지 각 1이며 종합 선택은 OpenCode입니다. 빌드 에이전트와 플랜 에이전트가 기본으로 들어 있고 무료에 MIT 라이선스이기 때문입니다. 다만 샌드박스가 없고 기본 권한이 느슨합니다
- 샌드박스와 사전 승인이 필요한 팀에는 Claude Code, 한 곳에 돈을 낸다면 Codex, 직접 작업 환경을 만들고 세션 중 모델을 바꾸고 싶다면 Pi입니다
- 벤치마크 결과는 모델과 하네스의 조합이라 모델이 바뀌면 점수판도 바뀝니다. 다음 영상은 모델을 제쳐 두고 루프만 평가합니다
