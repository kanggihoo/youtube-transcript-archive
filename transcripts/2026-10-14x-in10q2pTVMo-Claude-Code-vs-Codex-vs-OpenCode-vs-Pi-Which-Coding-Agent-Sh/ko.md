OpenCode 사용자들은 아직 마켓플레이스를 요청하는 중입니다. 플러그인, 에이전트, 스킬을 한곳에 모아 달라는 스레드가 하나 있고 반응이 41개 붙어 있습니다. Codex는 MCP 서버에 연결하며, 동작을 커밋하고 리뷰할 수 있는 설정 파일에 담아 둡니다.

**11:56** · 설정 표면을 보면 공정한 평가라고 생각합니다. OpenCode에서는 권한 규칙이 에이전트별, 명령 패턴별로 적용되고, 플러그인과 서브 에이전트도 같은 설정에 씁니다. OpenCode에 없는 것은 공식 에디터 확장이고, 이를 요청하는 반응이 174개입니다. Anthropic의 공식 플러그인 마켓플레이스는 가격을 미리 공개합니다.

**12:21** · 공식 항목은 설치 전에 컨텍스트 비용 추정치를 보여 주는데, 대부분의 사람들이 확인하지 않는 숫자입니다. Pi의 확장은 빌드 단계 없이 로드되는 TypeScript 모듈이며, JSON과 RPC를 쓰므로 이미 스크립트로 쓰는 어떤 것과도 연결됩니다. 이 확장들은 Pi 자체와 같은 운영체제 권한으로 실행되고, 서드파티 리뷰는 그래서 온보딩이 더 가파르다고 평가합니다. 확장성을 나란히 놓고, 각 방식의 밑에 깔린 비용도 같이 봅니다.
