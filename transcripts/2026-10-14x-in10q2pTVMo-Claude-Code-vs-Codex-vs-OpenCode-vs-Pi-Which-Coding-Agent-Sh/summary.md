# Claude Code vs Codex vs OpenCode vs Pi: Which Coding Agent Should You Use in 2026?

## 한 줄 요약

Full Stack은 터미널 코딩 에이전트 넷을 7개 항목으로 비교해 OpenCode 3승, Pi 2승, Claude Code와 Codex 각 1승으로 집계하고, 무료에 MIT 라이선스이며 plan 모드 등이 기본으로 있는 OpenCode를 전체 1위로 꼽습니다.

## 비교 대상

- Claude Code(Anthropic): 별 150,532개, 오픈소스 라이선스 없음, 유료 플랜에서 Opus 5.5로 연결
- Codex CLI(OpenAI): 별 128,968개, Apache 2.0, Rust 작성, ChatGPT 플랜에 포함
- OpenCode: 별 213,075개, MIT, build 에이전트와 plan 에이전트 제공
- Pi: 별 114,787개, MIT, 최소 하네스이며 15개 이상 제공자에 연결

## 비용: OpenCode 승

- Claude Code는 Pro 월 17~20달러, Max 월 100달러부터이고 5시간 롤링 창과 주간 상한이 있어 싼 플랜은 입구일 뿐이라고 봅니다
- Codex는 ChatGPT 플랜에 포함되고 Pro는 월 100, 200, 500달러이며 5시간 제한이 없는 등급입니다
- OpenCode는 무료이고 선택 사항인 go 플랜이 월 10달러입니다. 다만 무료라면서 구독이 필요하냐는 불만 스레드가 있습니다
- Pi는 하네스 비용이 없지만 포함된 사용량도 없어, 이미 모델 비용을 내는 경우에만 무료입니다. 푸터에 누적 비용을 보여 주는 점이 장점입니다

## 모델 연결 범위: Pi 승

- Pi는 15개 이상 제공자를 세션 도중 재시작 없이 바꿀 수 있고 커스텀 제공자도 받습니다. 기본 컨텍스트 창이 128k인 점과 Codex 연결의 신뢰성 스레드가 약점입니다
- OpenCode는 키가 있는 모든 제공자를 돌리지만 무료 모델은 기간 한정이고 그동안 데이터가 개선에 쓰일 수 있습니다

## 안전장치: Claude Code 승

- Claude Code는 읽기 전용으로 시작해 수정과 실행 전에 묻고, bash 샌드박스와 프롬프트 인젝션 방어가 있습니다
- Codex는 샌드박스와 승인을 분리하지만 로그인을 평문 파일에 캐시할 수 있습니다
- OpenCode는 반복 호출과 프로젝트 밖 경로에서 멈추고 명령 패턴별 허용, 질문, 차단이 되지만 기본값이 관대하고 샌드박스 요청은 열려 있습니다
- Pi는 권한 시스템이 없고 격리 방법을 문서로만 안내합니다

## 공개 벤치마크: Codex 승

- Terminal Bench 2.0에서 Codex가 GPT 5.5로 82.2%이고 Artificial Analysis 지수에서도 78.7점으로 선두입니다
- 점수는 모델과 하네스의 합이고 같은 모델도 10점 이상 움직입니다. 지수의 34개 행 중 20개가 Codex 변형이라 선두에는 표본 편중도 있습니다
- 호스트 모델을 고정하면 OpenCode 하네스가 65점, Claude Code가 57점입니다. Pi는 두 보드에 없습니다
- 해결한 과제당 비용은 27센트에서 1,180달러까지 벌어집니다

## 도입 한 달 뒤: OpenCode 승

- Codex는 릴리스 1,221개에 열린 이슈 약 2만 2천 개, 그중 버그 18,462개이고 macOS 앱의 CPU 폭주 보고가 있습니다
- Claude Code는 릴리스 241개에 열린 이슈 약 1만 4천 개이고, AGENTS.md 지원 요청이 2025년 8월부터 이어지고 있습니다
- OpenCode는 기여자 1,046명에 열린 이슈 3,322개이고 버그 라벨은 35개뿐이라 조심해서 읽어야 한다고 합니다
- Pi는 열린 이슈 239개이지만 긴 세션에서 CPU를 많이 쓰고 신규 기여자 이슈를 자동 종료합니다

## 확장성: Pi 승

- Claude Code는 마켓플레이스 플러그인, 스킬, 서브 에이전트, 훅, MCP를 지원하며 플러그인은 사용자 권한으로 돌아 신뢰 결정이 필요합니다. 공식 항목은 설치 전 컨텍스트 비용 추정치를 보여 줍니다
- Codex는 MCP와 커밋 가능한 설정 파일을 쓰지만 서드파티 평가는 확장성을 낮음에서 중간으로 봅니다
- OpenCode는 에이전트별, 패턴별 권한 규칙을 설정에 담지만 마켓플레이스와 공식 에디터 확장이 없습니다
- Pi의 확장은 빌드 없이 로드되는 TypeScript 모듈이고 JSON과 RPC를 쓰며, OS 권한으로 실행됩니다

## 설치: OpenCode 승

- Claude Code는 네이티브 설치가 자동 업데이트되어 가장 매끄럽지만 npm 경로는 폐기 예정이고 Windows 패키지 관리자 설치는 자동 업데이트가 안 됩니다
- Codex는 한 번 로그인으로 계정을 공유하지만 undo 명령이 제거됐고 Windows 독립 설치 프로그램이 없습니다
- OpenCode는 여러 패키지 관리자로 설치되며 Windows는 WSL을 안내하고, 버전 1과 2는 나란히 설치할 수 없습니다
- Pi는 Node 22.19 이상이 필요하고 업데이트 명령 하나로 최신을 유지합니다

## 결론과 추천

- 전체 1위는 OpenCode입니다. 무료에 MIT이고 build와 plan 에이전트가 기본이며 결정 요인은 비용입니다. 다만 샌드박스가 없고 권한 기본값이 관대하다는 점은 사용자가 판단해야 합니다
- 샌드박스와 승인이 먼저인 팀에는 Claude Code, 하나에만 돈을 낸다면 Codex, 하네스를 직접 만들며 세션 중 모델을 바꾸고 싶은 사람에게는 Pi를 추천합니다
- 다음 영상은 모델을 제외하고 루프만 점수를 매긴다고 예고합니다
