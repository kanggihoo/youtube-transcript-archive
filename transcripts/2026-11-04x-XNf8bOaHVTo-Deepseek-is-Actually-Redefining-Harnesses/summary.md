# Deepseek is Actually Redefining Harnesses!

## 결론부터

딥시크가 딥시크 하네스 크리에이터 모드(대화로 앱 플러그인을 만드는 기능)의 프롬프트 7개를 공개했고, 발표자(AICodeKing)는 이를 "플러그인 만드는 에이전트에게 말하는 법"의 교재로 읽습니다. 발표자의 결론은 위치·숫자와 기본값·제외 항목·채팅 연결을 프롬프트에 명시하고, 대화 왕복의 토큰 비용은 Cline Pass로 줄이라는 것입니다.

## 핵심 내용

- 발표자는 7개 프롬프트에서 규칙 7개를 뽑습니다. 위치 지정, 문제 발생 시 재시작 대신 구체적 지적, 형용사 대신 개수, 제외 항목과 기본값, 에이전트가 조작 가능한 플러그인, 상호작용의 단계별 서술, 실제 데이터 명시입니다.
- 이를 합쳐 좋은 프롬프트는 "어디에 있는지, 무엇을 하는지, 숫자와 기본값, 뺄 것, 채팅과의 연결"의 다섯 부분이라고 정리합니다.
- 크리에이터 모드는 여러 번 대화를 오가야 해서 토큰이 많이 든다며, 월 9.99달러 Cline Pass를 딥시크 하네스의 커스텀 모델 API로 연결하고 Cline Desktop·Panda Code를 병행하는 방법을 소개합니다.

## 배울 점과 적용 조건

- 에이전트에게 UI/플러그인을 만들게 할 때 위치, 개수, 기본값, 제외 항목, 실제 데이터 사용 여부를 한 번에 적는 체크리스트로 쓸 수 있습니다. 딥시크 하네스가 아닌 다른 코딩 에이전트에도 응용할 수 있는 일반 원칙입니다(작성자 보충).
- 딥시크 하네스에서 크리에이터 모드를 쓰려면 딥시크 하네스 설치와 모델 API(설정 → 모델 → 커스텀 모델 API, OpenAI chat completions 프로토콜)가 필요합니다.
- 발표자가 밝힌 제약은 딥시크 하네스가 개발자 프리뷰라 빌드마다 바뀌고, 프롬프트 하나로는 영상 결과가 재현되지 않으며, Cline Pass는 무제한이 아니고 Cline Desktop은 베타라는 점입니다.

## 근거와 한계

- **영상의 근거:** 딥시크가 공개한 7개 프롬프트 페이지를 하나씩 읽은 해설이 전부입니다. 실행 시연, 비용 측정, 모델 비교는 없습니다.
- **평가:** 프롬프트 문구에서 의도를 읽어 낸 해석은 그럴듯하지만, "첫 시도가 틀려서 문장을 추가했다" 같은 추정은 발표자의 추측입니다. 다섯 부분 구성이 결과 품질을 높인다는 비교 실험은 없습니다. 7번 프롬프트만 위치를 안 적어도 동작한다는 점은 위치 지정이 필수가 아닐 수 있음을 시사하지만 영상은 이를 다루지 않습니다.
- **확인 범위:** 자막 기반 평가입니다. 스타 수(26만 9천), MIT 라이선스, 10월 30일 빌드, Cline Pass 가격과 사용량 배수(2~5배)는 영상 내 주장이며 외부 미검증입니다.
- **홍보성:** 영상 중반 이후와 설명란이 Cline Pass, Cline Desktop 안내(설명란에 가입 링크 포함)로 채워져 있고 협찬 고지는 자막에 없습니다. 프롬프트 해설 부분은 이와 별개로 읽을 수 있습니다.
