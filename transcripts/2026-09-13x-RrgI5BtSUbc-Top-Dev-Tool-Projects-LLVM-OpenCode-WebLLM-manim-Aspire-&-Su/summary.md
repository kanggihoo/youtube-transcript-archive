# Top Dev Tool Projects : LLVM, OpenCode, WebLLM, manim, Aspire & Sugar High

## 한 줄 요약

터미널 코딩 에이전트, 온디바이스 브라우저 LLM, 팀 지식 동기화, 엔지니어링 규율 스킬, 웹 3D/비디오 생성 등 개발 생산성과 에이전트 협업을 혁신하는 20가지 최신 오픈소스 개발 도구를 소개한다.

## 핵심 오픈소스 개발 도구 20선

| 도구명 | 핵심 기능 및 차별점 | 라이선스 / 기반 기술 |
|---|---|---|
| **OpenCode** | 특정 모델에 종속되지 않는 터미널용 AI 코딩 에이전트 (빌드/플랜/서브 에이전트) | MIT |
| **Code-Graph-RAG** | Tree-sitter와 Memgraph 기반 지식 그래프로 모노레포 구조 분석 및 정확한 함수 탐색/패치 | MIT / MCP 지원 |
| **Agent Skills** | Google 공식 GCP 및 클라우드 인프라/ML 에이전트 교육용 마크다운 절차서 및 플러그인 | Apache 2.0 |
| **Skills For Real Engineers** | 바이브 코딩 대신 요구사항 인터뷰, 공통 언어 정의, TDD 피드백 등 엄격한 엔지니어링 원칙 주입 | MIT |
| **WebLLM** | WebGPU 기반으로 브라우저에서 서버 없이 LLM 직접 실행 (Llama, Gemma, Mistral 등 프라이버시 보장) | Apache 2.0 |
| **Codewhale** | Rust 기반의 경량·중립적 터미널 코딩 에이전트 (OS 샌드박싱, 단계별 승인, 복원 지원) | MIT |
| **TeamAI** | Git을 통해 팀 간 에이전트 스킬, 룰, 문서를 동기화하고 세션 마찰을 분석하는 지식 저장소 | MIT |
| **Pascal Editor** | React Three Fiber와 WebGPU를 활용한 브라우저 기반 오픈소스 3D 건축 설계 에디터 | MIT |
| **text-to-cad** | 자연어 지시로 기성 부품을 매칭하고 CAD/로보틱스 파일(STEP, STL, URDF) 및 G-code 생성 | Python / MIT |
| **openshaders** | React/JS 컴포넌트 및 CLI 패키지 형태로 설치 가능한 공유 웹 셰이더 플랫폼 | MIT |
| **PI-Desktop** | 클라우드 텔레메트리 없이 로컬에서만 동작하는 개인정보 보호 중심 코딩 에이전트 데스크톱 앱 | Electron / Rust |
| **ECC** | 코딩 에이전트에 계획-테스트-구현-검증-기억-개선 루프와 메모리 볼트를 추가하는 인지 프레임워크 | MIT |
| **hyperframes** | HTML/CSS와 GSAP/Three.js 코드를 헤드리스 크롬과 FFmpeg로 렌더링하는 결정론적 비디오 엔진 | Apache 2.0 |
| **Ruflo** | Claude Code와 Codex 상에서 동작하는 에이전트 군집(Swarm) 오케스트레이션 및 역할 분담 레이어 | MIT |
| **LLVM** | Clang, LLD, MLIR 등 재사용 가능한 모듈을 통해 다국어 프론트엔드 최적화 백엔드를 공유하는 툴체인 | Apache 2.0 |
| **Manim** | 타임라인 툴 대신 Python 코드로 수학 그래픽과 수식을 프로그래밍하여 렌더링하는 애니메이션 엔진 | MIT |
| **Distilly** | 실제 전문가의 대화와 문서에서 사고방식과 어조를 추출해 설치 가능한 에이전트 스킬로 패키징 | MIT |
| **zane-ops** | Docker Swarm과 Caddy 기반의 셀프 호스팅 배포 PaaS (Heroku/Railway의 경량 오픈소스 대안) | Open Source |
| **Aspire** | 마이크로소프트의 코드 기반 분산 멀티서비스 정의, 실행, 배포 및 OpenTelemetry 관측 툴체인 | MIT |
| **Sugar High** | 외부 의존성 없이 DOM 없는 환경에서도 초고속으로 코드를 컬러 HTML로 파싱하는 문법 하이라이터 | MIT |
