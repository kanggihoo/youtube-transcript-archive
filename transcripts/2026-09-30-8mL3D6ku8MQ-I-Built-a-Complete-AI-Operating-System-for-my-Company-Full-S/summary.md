# I Built a Complete AI Operating System for my Company (Full Stack)

## 한 줄 요약

회사 브레인(구조화된 폴더)만으로는 사업의 모든 일을 할 수 없으므로, 하니스(Claude Code·Codex), GitHub, n8n, 인피니티 OS, Buzz, StarMind Connect·Data를 브레인에 붙여 데이터와 맥락을 갖고 직접 행동하는 "AI 운영체제"를 만들 수 있다는 AI Impact의 아키텍처 소개 영상이다.

## 회사 브레인은 폴더일 뿐이다

- 브레인은 앱이 아니라 파일이 든 폴더이며, 회사에 필요한 모든 것의 색인을 두어 AI가 필요한 것을 찾게 한다. 에이전트, 스킬, 규칙, 워크플로, 맞춤 도구, 지식 그래프, 데이터, 메모리, 산출물, 프로젝트와 부서가 들어간다
- 브레인은 브레인 자체와 런타임(인피니티 OS) 두 부분으로 이루어진다
- AI가 올바른 데이터·맥락과 올바른 도구를 갖추면 사업에서 거의 무엇이든 할 수 있다는 것이 AI 운영체제의 전제다
- 관찰·방향 설정·결정·실행(OODA) 순환을 AI가 점점 완성해 가고 있다고 본다

## 하니스와 GitHub: 브레인 위에서 대화하는 규칙

- Claude Chat, Claude Co-worker, Grok Bot처럼 단순 대화만 하는 도구는 브레인 위에 있는 것이 아니다
- Claude Code, Codex, VS Code처럼 폴더에 연결되는 도구는 "브레인 하니스"로 쓸 수 있다. 하니스는 어댑터일 뿐이다
- 브레인은 GitHub와 동기화하며, 비즈니스 사용자도 GitHub를 써야 한다고 권한다
- 데이터 분석과 실행 두 축은 사람이 분석하고 결정하게 하며, 둘을 잇는 다리는 브레인이 완전히 갖춰진 뒤에 만들기를 권한다

## 행동은 n8n에 맡긴다

- 아인슈타인의 브레인도 리모컨을 옮기는 일에는 맞지 않듯, 브레인은 행동 처리에 맞지 않아 별도 도구가 필요하다
- 자체 호스팅한 n8n을 권한다. 무료이고 코드가 쉽게 보이며, 오픈소스라 코드를 소유할 수 있고, 오래 쓰여 지속성이 있으며 큰 회사까지 확장된다
- 트리거, 분석, 정규화·필터링, 전달 같은 단계를 시각적으로 이어 붙이며 수십 단계나 조건 분기도 가능하다

## 인피니티 OS: 무료 오픈소스 런타임

- 여러 OS(브레인)를 두어 여러 회사나 부서를 다룰 수 있다
- 받은편지함 대신 큐를 둔다. 들어오는 거의 모든 것이 AI 검토를 거쳐 AI가 대신 답하거나 정리하거나 큐에 올린다. 환불 요청이면 AI가 옵션을 제시하고 사람이 고르면 AI가 처리한다
- n8n과 동기화되어 흐름과 최근 실행 내역을 볼 수 있다
- 모든 AI 채팅(ChatGPT, Claude, 팀 전체)이 자체 서버와 API를 통해 한곳에 동기화된다. 승인 같은 작업도 Claude Code 채팅이 아니라 여기서 처리한다
- 현재 베타이며 이메일 목록 가입으로 접근한다

## Buzz: AI와 통합된 오픈소스 메신저

- 슬랙과 비슷하지만 AI와 기본 통합되고 무료이며 오픈소스로 보유할 수 있다
- 채팅에서 에이전트를 불러 "이건 브레인 어디에 있지?" 같은 질문을 할 수 있다
- 인피니티 OS와 동기화되어 에이전트가 API 호출 없이 채널 내용에 접근한다. 발표자는 슬랙에서 이쪽으로 옮겨 가는 중이다

## 키·비밀번호는 브레인 밖에: StarMind Connect

- API 키를 브레인에 저장하면 안 되지만 AI는 키가 어디 있는지 알아야 하는 모순이 있다
- Open Claude는 키를 책임 있게 다루지 않았고, OpenAI와 Claude에 키를 올리면 유출되지 않는다는 보장이 없다고 말한다. 1Password나 Google Secret Manager 연동도 선택지다
- StarMind Connect는 브레인에는 별칭(가짜 이름)만 두고 진짜 값은 금고에 보관한다. 코드를 서비스로 보내기 직전에 파이썬 스크립트로 별칭을 실제 값으로 바꿔, AI가 비밀번호를 쓰되 값은 모르게 한다
- 누가 비밀번호를 쓰는지 활동을 볼 수 있어 통제 불능 에이전트를 감시할 수 있다. 이 도구는 오픈소스가 아니며 베타 중이다

## 숫자는 데이터베이스에: StarMind Data

- 숫자도 브레인에 넣지 않는다. 브레인이 너무 커지므로 데이터가 어디 있는지 알려 주는 디렉터리만 둔다
- 데이터 웨어하우스나 백엔드 DB를 AI가 쓸 수 있게 구조화해야 하는데, BI·데이터 엔지니어링 부서가 없는 회사를 위해 데이터를 DB로 가져오는 StarMind Data를 준비 중이며 일부 고객에게는 이미 작동한다
- 인피니티 OS에서 대시보드와 AI 보고서를 만들어 Power BI가 하던 일을 대신하고, 에이전트와 팀이 같은 보고서를 본다
- 가격은 StarMind(시크릿·비밀번호·데이터)가 월 29달러, 인피니티 OS는 무료다

## 전체 구성과 오픈소스·재단 구상

- 구성은 Claude Code/Codex를 브레인에 연결하고, 브레인(GitHub)을 인피니티 OS와 동기화하며, 대화는 Buzz, 일상 운영은 인피니티 OS, 행동은 n8n, 키는 StarMind Connect, 숫자는 StarMind Data가 맡는 형태다
- 인피니티 브레인을 몇 달 전 오픈소스로 공개했고, 고객 사례에서 발견한 빈틈을 메우려고 인피니티 OS를 만들었다
- 사업과 일상의 AI를 운영하는 것은 사용자가 소유하는 시스템이어야 한다는 신념으로 비영리 인피니티 OS 재단을 설립 중이며, 팀이 생산성을 100배 높이는 AI 시스템을 소유하게 하는 것이 목표다
