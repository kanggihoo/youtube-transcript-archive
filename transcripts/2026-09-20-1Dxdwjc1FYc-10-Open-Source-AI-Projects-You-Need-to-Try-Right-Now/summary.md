# 실제 에이전트에는 모델 외에도 실행 환경, 도구, 구조화된 출력, 메모리와 평가가 필요하다. 영상은 이 역할을 각각 보완하는 10개 프로젝트를 작업 유형별로 소개한다.

## 코딩과 워크플로 실행

OpenHands는 저장소에서 파일을 바꾸고 명령을 실행하는 코딩 작업 환경을 제공한다. OpenAI Agents SDK와 Google ADK는 도구 호출과 다단계 워크플로를 구성한다. GitHub Spec Kit은 구현 전 요구사항·계획·작업을 명시한다.

## 출력, 모델, 메모리

Pydantic AI는 구조화 출력을 검증하고 LiteLLM은 모델 제공자 라우팅과 대체 경로를 지원한다. Letta는 상호작용 간 상태를 유지하는 메모리 기반 에이전트를 다룬다. DSPy는 평가를 통해 작업 프로그램을 최적화한다.

## 인터페이스와 품질 확인

Browser Use는 웹 UI 자동화를 제공하며 Promptfoo는 변경 후 평가를 반복 실행한다. 프로젝트 전체를 도입하기보다 에이전트가 맡을 실제 업무에서 필요한 기능을 고르는 것이 핵심이다.
