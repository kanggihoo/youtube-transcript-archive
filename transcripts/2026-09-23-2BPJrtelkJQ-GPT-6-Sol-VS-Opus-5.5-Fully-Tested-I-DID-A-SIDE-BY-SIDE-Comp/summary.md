# 영상의 공개 벤치마크와 평가자 자체 과제에서 Opus 5.5는 복잡한 인터랙션과 앱 완성도에서 더 좋은 결과를 냈고, Soul은 더 낮은 API 비용이 강점이었다. 자체 평가는 주관적이며 수정에 드는 총비용은 측정하지 않았다.

## 벤치마크와 비용

Artificial Analysis 지수에서 Opus가 중간·최대 노력 설정 모두 Soul을 앞섰고, 평가 과제당 비용은 이 시험 설정에서 더 높았다. Soul은 입력이 27만 2천 토큰을 넘을 때 요금이 달라진다. 벤치마크 설정과 제공자별 노력 수준을 함께 고려해야 한다.

## KingBench 3 결과

8개 과제 합계는 Opus 75/80, Soul 66/80이었다. 렌즈 케이스와 활쏘기처럼 물리적 동작과 인터랙션이 중요한 과제에서 격차가 컸다. 반면 SVG, 조합론 문제, 판다 미세 조정, 손목시계는 두 모델이 모두 만점을 받았다.

## 장시간 앱 제작

영화 추적기, 포스터 앱, 블루레이 컬렉션, Obsidian형 앱에서 평가자는 Opus의 기능 완성도와 세부 표현을 더 높게 봤다. Soul도 일부 과제에서 좋은 결과를 냈으며, 영상의 최종 선택은 발표자의 작업 유형과 취향에 따른 평가다.
