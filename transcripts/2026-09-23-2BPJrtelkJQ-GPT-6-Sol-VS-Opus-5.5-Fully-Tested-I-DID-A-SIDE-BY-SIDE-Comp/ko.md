# 한국어 번역

안녕하세요. OpenAI는 GPT-6 Soul을, Anthropic은 Claude Opus 5.5를 출시했습니다. 두 모델은 9월 22일 나왔고 더 낮은 비용에 더 나은 결과를 약속합니다. 제 시험에서는 콘택트렌즈 케이스, 엘리베이터 시뮬레이션, 큰 앱 제작에서 차이가 뚜렷했습니다. 둘 다 비슷하게 잘한 과제도 있습니다. 공개 벤치마크와 KingBench 3, 장시간 앱 제작 테스트를 살펴보겠습니다.

GPT-6는 Astra의 발전을 더 저렴한 모델에 가져왔다고 OpenAI는 설명합니다. Soul은 코딩, 컴퓨터 사용, 사실 신뢰성, 의사소통이 개선됐습니다. OpenAI의 내부 사실성 시험에서 GPT-5.6보다 실수가 약 절반이었다고 하지만, 모든 답이 두 배 정확하다는 의미는 아닙니다. Soul 가격은 입력 토큰 100만 개당 2달러, 출력 100만 개당 10달러로 이전 GPT-5.6 Soul 프로모션 가격의 절반입니다. ChatGPT, Codex, API에서 출시됐습니다. 반복적으로 같은 지침과 컨텍스트를 읽는 에이전트는 프롬프트 캐싱으로 더 많은 작업을 재사용할 수 있습니다.

Anthropic에 따르면 Opus 5.5는 Opus 5보다 30% 넘게 빠르고 일반 작업 비용은 기본 설정에서 약 40% 낮습니다. 밀도 높은 차트와 스크린샷을 더 정확히 읽으며 적응형 사고가 항상 켜져 있고 기본 노력은 중간입니다. API 가격은 입력 100만 토큰당 4달러, 출력 20달러입니다. Soul의 표준 입출력 요금은 절반입니다. 캐시 입력은 둘 다 100만 토큰당 20센트입니다. 컨텍스트는 약 100만 토큰이고 기본 최대 출력은 12만 8천 토큰입니다. Soul의 정확한 컨텍스트 한도는 15만 토큰입니다. Soul은 입력이 27만 2천 토큰을 넘으면 요금이 올라갑니다.

## 공개 벤치마크

Artificial Analysis Intelligence Index 4.3.2에서 GPT-6 Soul 중간 설정은 40점, Opus 5.5 중간 설정은 51점이었습니다. 최대 노력 설정에서는 각각 48점과 58점입니다. 지수 점수는 퍼센트가 아닙니다. Opus가 앞서지만 비용 차이가 있습니다. 중간 설정의 평가 과제당 가중 비용은 Soul 약 25센트, Opus 1.34달러로 보고되어 Opus가 약 5.4배입니다. 안전장치가 개입한 Opus 결과에는 다른 Claude 모델로의 대체가 포함됐습니다. 제공자별 중간 설정은 계산량이 같지 않으므로 시험된 설정끼리 비교해야 합니다.

Terminal Bench 4.0에서 Opus 중간 설정은 53%, Soul은 19%로 보고됐습니다. Side Code는 59% 대 54%, Humanities Last Exam은 55 대 41, Automation Bench-AA는 61 대 58입니다. 모두 Artificial Analysis의 측정입니다. 도구와 점수 방식이 출시 벤치마크와 다를 수 있습니다. 공개 결과는 Opus의 우세와 Soul의 비용 이점을 함께 보여줍니다.

## KingBench 3의 8개 과제

두 모델을 중간 노력 설정으로 시험했습니다. 기능, 시각 품질, 요청 준수도를 합쳐 각 과제를 10점 만점으로 평가했습니다.

엘리베이터 시뮬레이션에서는 한 번에 한 사람만 탈 수 있는 엘리베이터 3개와 층별 목적지를 요청했습니다. Opus는 설계는 평범했지만 핵심 동작을 잘 구현해 8점, Soul은 디자인이 전형적인 AI 스타일이고 동작도 부정확해 7점입니다.

3D 콘택트렌즈 케이스에서는 왼쪽·오른쪽 칸과 클릭 가능한 뚜껑을 요청했습니다. Opus는 케이스 안의 렌즈까지 잘 표현해 10점이었습니다. Soul 버전은 뚜껑이 형상과 겹쳐 상호작용이 어색했고 6점으로, 가장 큰 격차였습니다.

접이식 테이블은 슬라이더로 접고 펴게 하는 과제였습니다. 둘 다 괜찮았지만 Opus가 더 나아 8점, Soul은 7점입니다. 판다의 햄버거 SVG는 둘 다 좋았고 10점씩 받았습니다.

활쏘기 게임은 표적 네 개와 빠른 완료에 따른 순위표를 요청했습니다. Soul은 단순하고 화살 궤적이 곡선이 아니었습니다. Opus는 더 나은 게임과 난도 있는 동작을 구현해 9점, Soul은 6점입니다. 조합론 문제의 정답 20,460은 둘 다 맞혀 10점씩 받았습니다.

판다 사실 데이터셋 생성, Gemma 2B 미세 조정, 새로고침할 때 판다 정보를 보여주는 로컬 웹 인터페이스 과제도 둘 다 10점이었습니다. 현재 시각을 반영하는 부드러운 시계 바늘, 날짜·요일, 두 시간대를 넣은 3D 손목시계도 모두 10점입니다.

합계는 Opus 75/80(93.75%), Soul 66/80(82.5%)로 Opus가 11.25%포인트 앞섰습니다. 이 평가자의 KingBench 3 순위에서는 Opus가 1위, Soul은 Fable 5와 비슷한 82.55%였습니다. 차이는 물리적 동작, 인터랙션, 완성도에서 나타났습니다.

## 장시간 앱 제작

TMDB API와 포스터 이미지를 쓰고 터미널 크기·글꼴에 대응하는 영화 추적 앱에서 Soul은 포스터가 나오지 않고 미완성처럼 보였습니다. Opus는 기능이 제대로 작동했고 출시 가능한 앱처럼 느껴졌다고 평가자는 말합니다.

A4 포스터 생성·인쇄와 3D 액자 미리보기를 갖춘 앱은 Opus의 디자인과 API 기능이 낫지만 격차는 더 작았습니다. 3D 블루레이 컬렉션은 Soul도 3D 배치와 기능을 잘 구현했으나 Opus가 더 현실적인 전환과 세부 표현을 했습니다. 마지막으로 Markdown 파일, 애니메이션, 파일 기반 이미지 생성, 열린 파일 문맥을 쓰는 에이전트가 있는 Obsidian형 앱에서는 Soul도 기능은 있었지만 전형적인 디자인이었고 Opus의 결과가 더 요구에 가까웠습니다.

발표자는 앱 제작 과제에서 Opus를 선호합니다. Soul의 가격과 네 과제 만점은 강점이지만, 전형적인 프런트엔드나 빠진 인터랙션을 수정하는 데 시간을 쓸 수 있다고 합니다. 수정 비용은 이 시험에서 측정하지 않았습니다. 결과물의 전체 완성도와 기능을 꾸준히 맞춘 점에서 Opus가 자신에게 맞았다는 결론입니다.
