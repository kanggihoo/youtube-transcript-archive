# How I Code Without Typing

## 한 줄 요약

손 부상으로 양손 타이핑(기존 160 WPM)이 불가능해진 개발자 Theo(t3.gg)가, 70달러짜리 초저소음 단상 마이크 기반 속삭임 음성 입력(Whisper Flow)과 에이전트의 개입 경계를 극단적으로 앞당기고 늘린(문제 정의부터 150건의 자율 YOLO 머지까지) 워크플로를 통해 역대 최고 배포량을 달성한 실전 비결을 공유한다.

## 하드웨어 및 입력 인터페이스 혁신

- **음성 코딩의 현실적 한계**: 코드 문법 자체를 말로 치는 것은 불가능하며, 자연어 의도를 지시하는 데 음성을 활용해야 함.
- **70달러 단상용 마이크(Podium Mic) + Whisper Flow**:
  - 방송용 콘덴서 마이크와 달리 정상 발성 대비 -40dB 수준의 극단적인 '속삭임'을 정확히 인식.
  - 사무실 환경에서 주변 동료에게 방해를 주지 않고, 옆자리 대화나 영상 소음을 완벽히 차단하여 음성 지시의 심리적 장벽 극복.
- **모바일 스와이프 입력 활용**: 양손을 강제하는 PC 키보드 대신 한 손 스와이프 입력이 가능한 스마트폰 환경에서 T3 Code를 통해 원격 에이전트 제어.

## 개발 환경의 전환: 터미널 탈피와 원격 머신 인프라(`fleet`)

- **터미널 인터페이스 기피**: 음성으로 CLI 명령어를 다루는 비효율을 제거하고, 에이전트 네이티브 GUI(T3 Code)로 전면 전환.
- **`fleet` 리포지토리 기반 인프라 오케스트레이션**:
  - 보유한 여러 대의 Mac/PC 접속 정보와 역할을 에이전트에게 사전 인덱싱.
  - 파일 다운로드 후 다른 PC 전송, 신규 브랜치 격리 빌드 등 과거 터미널/SSH로 수행하던 인프라 작업을 음성 지시 한 줄로 자율 처리.

## 에이전트 워크플로의 패러다임 전환: 경계의 극단적 확장

1. **더 이른 투입 (Sooner)**:
   - 개발자가 직접 브랜치를 찾거나, 레포를 클론하고, 요구사항을 정리하지 않고 머릿속에 떠오른 문제와 버그를 날것 그대로 에이전트에 브레인 덤프.
2. **더 긴 자율 실행 (Longer)**:
   - 구현뿐만 아니라 컴퓨터 유즈(Computer Use), 리포지토리 코드 리뷰 봇, 서브 에이전트 검증을 강제하여 "사용자 관점의 결함이 없다고 확신할 때까지 인간을 방해하지 말라"고 위임.
3. **자율 머지 (YOLO Merges)**:
   - Astra와 Fable에게 150건 이상의 PR을 전자율로 작성·검증·머지시켰으며, 사소한 애니메이션 누락 2건을 제외하고 무결점 배포(인간 개발자 이상의 성공률 입증).
4. **게으른 컨텍스트 전달 (Lazy Context Passing)**:
   - 스레드 간에 수동으로 코드나 PR 정보를 복사·붙여넣기하지 않고, "오늘 리뷰한 PR 중 중요한 3개를 네가 직접 찾아서 평가해 봐"처럼 에이전트의 도구 탐색 능력을 최대한 활용.
