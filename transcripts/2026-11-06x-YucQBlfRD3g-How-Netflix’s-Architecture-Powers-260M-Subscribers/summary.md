# How Netflix’s Architecture Powers 260M Subscribers

## 결론부터

넷플릭스가 CDN(Open Connect), 장애 주입(Chaos Monkey), 마이크로서비스, Cassandra, Kafka, Spinnaker 등 각 계층을 어떤 자체 도구로 풀었는지 나열하는 개관 영상입니다. 발표자의 결론은 단일 만능 기술이 아니라 문제마다 맞는 도구를 직접 만들어 조합한 것이 넷플릭스 규모의 비결이라는 것입니다.

## 핵심 내용

- **콘텐츠 전송 (0:00-2:00):** Open Connect라는 자체 CDN입니다. 발표자는 OCA(Open Connect Appliance)라는 맞춤형 스토리지 장비를 사용자 지역 ISP 데이터센터 안에 직접 설치해, 영상이 먼 곳에서 오지 않고 가까운 곳에서 내려온다고 설명합니다.
- **복원력과 클라우드 (2:00-3:36):** Chaos Monkey가 업무 시간에 프로덕션 서버를 일부러 죽여 장애에 강한 설계를 강제합니다. 2008년 DB 손상으로 DVD 배송이 3일간 멈춘 사고가 AWS 이전의 계기였다고 말합니다.
- **마이크로서비스와 서비스 운영 (3:36-9:57):** 모놀리스를 천 개 이상의 마이크로서비스로 쪼개고, Titus(컨테이너), Zuul(게이트웨이), Eureka·Ribbon(서비스 디스커버리와 로드 밸런싱)으로 운영합니다. 시청 기록은 Cassandra에 저장합니다. 이어서 동적 인코딩으로 대역폭을 아낀다고 합니다(9:57-11:03).
- **데이터와 개인화 (11:03-14:08):** 이벤트는 Kafka로 실시간 처리하고, 썸네일은 컨텍스추얼 밴딧으로 사용자별로 개인화합니다. 프런트엔드는 Node.js와 React를 쓴다고 합니다.
- **관측과 배포 (14:08-17:00):** Vector와 Mantis로 문제를 잡고, Hollow가 데이터 세트 전체를 각 서비스의 로컬 RAM에 캐시합니다. Spinnaker는 카나리 배포와 자동 롤백을 맡습니다.
- **데이터 모델과 AI 플랫폼 (17:00-19:14):** Falcor로 연결된 데이터를 다루고, 용도별로 저장소를 나눕니다(폴리글랏 퍼시스턴스). AI 플랫폼 Darwin은 데이터 과학자가 클라우드 프로비저닝을 신경 쓰지 않고 모델을 학습·배포하게 한다고 합니다.

## 배울 점과 적용 조건

- 장애 주입, 서비스 디스커버리, 카나리 배포, 용도별 저장소 분리는 개념으로 배워 둘 만합니다. 다만 영상은 도입 조건·비용을 다루지 않으며, 수백 개 서비스와 전담 플랫폼 팀이 있는 규모를 전제로 한 설계입니다.
- 영상에 나온 도구 이름(Zuul, Eureka, Hollow, Spinnaker, MezzFS, Mantis 등)은 공식 저장소·블로그를 찾아볼 키워드로 쓸 수 있습니다.

## 근거와 한계

- **영상의 근거:** 아키텍처 다이어그램, 코드, 운영 지표 화면, 출처 인용이 없습니다. 모든 설명은 나레이션입니다.
- **평가:** "15% 인터넷 트래픽", "하루 1조 건 이벤트", "저가 TV에서 60fps" 같은 수치는 출처와 시점이 없어 근거가 약합니다. 설명 톤도 "genuinely unhinged", "천재적인 트릭" 등 과장이 섞여 있습니다. Eureka·Ribbon·Zuul·Titus 등이 현재도 같은 형태로 쓰이는지, 이미 대체됐는지는 영상이 다루지 않습니다.
- **확인 범위:** 자막 기반 평가이며, 외부 확인은 한 건만 했습니다. (작성자 보충, 확인 시점 2026-11-06)
  - Falcor: 영상은 "넷플릭스 전체를 그래프로 다루며 그래프 순회 알고리즘으로 관계를 계산하는 데이터 서비스"라고 하지만, 프로젝트 공식 문서는 Falcor를 가상 JSON 그래프 위에서 원격 데이터를 하나의 모델처럼 가져오게 하는 **자바스크립트 데이터 페칭 라이브러리**로 설명합니다. 추천 관계 계산용 그래프 DB가 아니므로 영상 설명은 부정확합니다. ([Falcor 공식 문서](https://netflix.github.io/falcor))
  - 나머지 구성 요소와 수치는 영상 내 주장, 외부 미검증입니다.
  - 자막의 "Holo", "Mez FS", "Falkor"는 각각 Hollow, MezzFS, Falcor의 자동 자막 오기로 보이며, 번역본에서는 바로잡았습니다.
- **홍보성:** 협찬 고지나 제품 유도는 관찰되지 않았습니다.
