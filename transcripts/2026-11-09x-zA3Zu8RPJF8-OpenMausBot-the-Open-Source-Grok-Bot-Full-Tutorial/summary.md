# OpenMausBot — the Open-Source Grok Bot (Full Tutorial)

## 결론부터

Full Stack은 Claude Code·Codex·Grok CLI를 내 컴퓨터에서 채팅형 봇 명단으로 묶어 주는 오픈소스 OpenMausBot을, 클라우드에서만 도는 유료 제품 Grok Bot과 비교해 소개한다. 이미 Claude나 ChatGPT를 구독 중이고 데이터를 내 디스크에 두고 싶다면 써 볼 만하지만, 새 봇은 승인 없이 모든 작업을 하는 full access로 시작하므로 반드시 ask 모드로 바꾸라고 권한다.

## 핵심 내용

- **구조:** 데스크톱 앱(채팅 UI)과 harness 서버 두 프로세스가 돌며, harness는 localhost에서만 수신하고 각 에이전트 CLI를 사용자 로그인 그대로 자식 프로세스로 실행한다. 세 도구의 서로 다른 프로토콜을 하나의 이벤트 스트림으로 변환해 대화별로 디스크에 기록한다. 새 엔진은 약 600줄 드라이버 파일과 등록 한 줄로, ACP 또는 OpenAI 호환 엔드포인트는 설정만으로 붙는다.
- **기능:** 봇마다 모델을 고르고(대화 중 변경 가능), 컴퓨터는 클라우드 박스(스폰서 서비스, 체험 후 유료)·로컬 VM(Docker/Podman)·내 Mac 직접 제어 중 선택한다. 앱 연동은 Composio(500개 이상 앱)로, 메모리는 디스크의 일반 markdown 파일(첫 200줄/24KB만 로드, API 키는 저장 전 마스킹)이다. 채널·자동 라우팅(점수 0.6 미만이면 리드가 응답)·스케줄·웹훅·팀 파일 설치·CLI/MCP·서버 모드도 있다.
- **포기하는 것:** 관찰로 루틴을 학습하는 기능이 없고, 노트북을 닫으면 에이전트가 멈추며, 모바일 지원은 아직 초기 단계다. 발표자는 README가 스스로 "early but real"이라 표기한다고 전한다.

## 배울 점과 적용 조건

- **보안:** 승인 카드(허용/거부)가 README의 대표 기능인데 새 봇과 새 대화는 기본이 full access라 카드가 꺼져 있다. 이메일 앱이 연결된 봇은 일일 한도 없이 발송할 수 있다. 발표자의 규칙: 컴퓨터나 앱을 주기 전에 모든 봇을 ask로 두고, 동작을 지켜본 뒤 완화한다.
- 적용 전제는 에이전트 CLI(Claude Code, Codex, Grok CLI)가 이미 설치·로그인되어 있는 것이다. 비용은 앱 무료, 모델 구독료와 선택 서비스(클라우드 박스 등)만 든다.
- 서버로 돌릴 때 포트 8799를 직접 외부에 열지 말라는 것이 공식 문서 경고라고 한다.

## 근거와 한계

- **영상의 근거:** README와 공식 문서, 제작자의 비교 글 인용과 앱 화면 설명. 발표자가 직접 설치·사용한 결과나 벤치마크는 제시하지 않는다.
- **평가:** 설계 설명(두 프로세스, 드라이버, 비밀 키 처리)은 구체적이어서 신뢰할 만하지만 안정성·보안은 코드 감사 없이는 판단할 수 없다. 약 1만 7천 개발자가 3개월 내 시작했다는 수치와 가격($30, $20)은 README나 업체 정보 인용이다.
- **확인 범위:** 자막 기반이다. 저장소, 릴리스, 문서는 열어 보지 않았다. 자동 자막에 제품명이 틀리게 표기된 곳이 많다(Grok Bot/Grox Bot, OpenMausBot/Open Mouse Bot 등). 영상 내 주장, 외부 미검증.
- **홍보성:** 저장소 스타 요청과 구독 유도가 있다. 클라우드 박스는 프로젝트 스폰서의 유료 서비스라고 밝히며, 협찬 고지는 자막에서 확인되지 않는다.
