# 오픈 모델 돌리려면 1000만원... 그냥 Runpod에서 빌려 씁니다 | RTX 5090 + Qwen 3.8

## 한 줄 요약

270억 파라미터 Qwen 3.8을 개인 장비로 돌리려면 약 1000만 원이 들지만, 24시간 상시 가동이 아니라면 Runpod에서 RTX 5090을 시간당 약 0.7달러에 빌려 vLLM으로 띄우고 Codex에 붙여 쓰는 편이 훨씬 싸다는 튜토리얼입니다. 영상에는 Runpod의 유료 광고가 포함되어 있습니다.

## 왜 Qwen 3.8 27B이고, 왜 빌리나

발표자는 개인 GPU에서 현실적으로 돌릴 수 있는 규모(40억~400억 파라미터) 중 270억짜리 Qwen 3.8이 가장 적합하다고 봅니다. 추론을 최대로 올린 Intelligence 점수가 Qwen 3.8 34, Opus 4.5 29, GPT 5 23으로, 1년 전 프런티어 모델보다 높습니다. 다만 두 모델은 작년 말 출시라는 점을 감안해야 한다고 덧붙입니다.

문제는 장비 가격입니다. RTX 5090은 870만~960만 원대로 출시 때의 거의 두 배이고, DGX Spark도 비슷합니다. PC까지 더하면 약 1000만 원입니다.

## 손익분기: 24시간 돌리면 사고, 아니면 빌린다

- 5090을 Runpod에서 시간당 약 0.99달러로 계산하면 870만 원은 약 6,500시간, 하루 24시간 쉬지 않고 약 9개월입니다. 그보다 오래 상시 가동한다면 사는 쪽이 유리합니다
- 하루 한두 시간만 쓰면 본전까지 약 9년입니다
- 이 계산은 그래픽카드 값만 반영한 것이고 PC와 전기요금은 빠져 있습니다
- 가끔 쓰거나 구매 전에 성능을 시험해 보려는 경우에 Runpod를 권합니다

## Pod 만들기: 설정 순서

1. **vLLM 템플릿 선택 후 Override.** 컨테이너 이미지는 latest 대신 **0.29.00으로 고정**하고, 시작 명령어는 설명란 가이드에 있는 것으로 교체합니다. 컨테이너 디스크는 60GB면 충분합니다
2. **API 키 교체.** 기본값은 안전하지 않으니 직접 키를 생성하고, Runpod Secret에 저장해 환경 변수에 연결합니다
3. **GPU 필터.** Cloud Type은 Secure(Runpod 데이터센터, 더 안정적이고 비쌈)와 Community(인증된 소규모 호스트·개인, 더 쌈) 중 테스트용으로 Community를 선택했습니다. CUDA는 13 이상(13.1)으로 맞추고 RTX 5090을 고릅니다. Community 기준 GPU 0.69달러, Secure라면 0.99달러입니다
4. **Deploy.** 서버가 준비되기까지 10~15분 걸립니다. Connect 탭의 HTTP 서비스가 Ready로 바뀌면 끝입니다

## 동작 확인과 Codex 연결

웹 터미널에서 `nvidia-smi`로 GPU를, `curl`로 모델 인식과 간단한 대화를 확인합니다("누구냐"는 질문에 알리바바에서 만든 모델이라고 답함).

Codex는 홈 디렉터리에 Runpod 전용 `config.toml`을 따로 만들고 Base URL의 버전 앞부분만 Pod의 HTTP 주소로 바꿉니다. vLLM API 키는 환경 변수로 export하고, Codex Home을 그 경로로 지정해 실행합니다. 코드 생성 속도는 예상보다 빨랐고, 설정 파일의 Model Reasoning을 Low에서 X High로 바꿔 추론 강도를 올려 볼 수 있습니다.

## 요금과 Stop vs Terminate

- 컴퓨터·GPU·컨테이너를 합친 시간당 비용은 약 0.70달러이고, 47~48분 쓴 시점에도 0.70달러가 안 됐습니다
- **Stop**은 GPU 과금만 멈추고 Pod를 남겨 같은 설정으로 다시 시작할 수 있게 합니다. 디스크 요금은 계속 나갈 수 있습니다
- **Terminate**는 Pod를 완전히 삭제합니다. 오래 안 쓸 거라면 Terminate를 권합니다

## 써 본 소감과 쓸 만한 상황

- 속도는 예상보다 빨랐고 270억 모델 치고 코드 품질이 좋았습니다. 단순 코딩과 테스트·수정은 무리 없이 됐습니다. 최신 프런티어 모델 수준은 아닙니다
- Pod 기동에 10~15분이 걸리는 게 단점입니다
- 하루 네댓 시간씩 쓰고 끄는 패턴이면 Pod가 맞고, 이미지 생성 모델처럼 요청이 올 때만 켜려면 서버리스를 고려하라고 합니다(서버리스는 다루지 않음)
- 새 오픈 모델 테스트, 기업 교육에서 수강생에게 엔드포인트 공유(호출 횟수와 무관하게 시간당 비용), 팀 단위 시험, 파인튜닝처럼 짧게 GPU를 많이 쓰는 작업에 유용합니다
- 기존 클라우드 대비 최대 90% 저렴한 경우도 있다고 하며, 여러 서비스와 비교해 보라고 권합니다

## 주의할 점

Pod 주소와 API 키만 알면 누구나 요청할 수 있으므로 키가 유출되지 않게 관리해야 합니다. 기본 값 대신 직접 만든 키를 Secret에 보관하세요.
