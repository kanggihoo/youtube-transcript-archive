# Claude Code's #1 Token Saving Skill Just Got Upgraded (But Is It BS?)

## 한 줄 요약

Ponytail 5의 절감 수치(코드 61%, 비용 24%, 시간 35%)는 700개 세션 테스트에서 사실로 확인됐지만, 요구가 모호한 작업에서는 Claude가 채워 주던 부가 기능까지 잘라 내므로 상세한 명세를 주는 사람에게만 맞는다고 평가합니다.

## 버전 5의 다섯 가지 변경

- 규칙이 1,000단어 가까이에서 600단어로 줄었고 출력은 버전 4보다 약 10% 쌉니다
- 코드를 쓰기 전에 작업과 건드릴 코드를 읽고 변경이 미칠 지점을 모두 나열합니다
- 건너뛴 것, 확인하지 않은 것, 위험하다고 보는 것을 반드시 말해야 합니다. 버전 4에서는 선택 사항이었습니다
- review와 audit이 과잉 설계뿐 아니라 버그, 보안, 누락된 테스트, 속도까지 봅니다
- 프롬프트 위에 비용, 토큰, 에이전트 시간, 재사용, 테스트를 보여 주는 라이브 밴드와, 세션 시작 시 기존 함수를 나열하는 저장소 지도가 추가됐습니다

## 핵심 원리

- Claude는 원래 말이 많다는 전제 아래 꼭 필요한 것만 만들게 합니다. 기능을 만들 때마다 "이게 존재해야 하나"부터 "한 줄로 되나"까지 일곱 가지 질문을 거칩니다
- 날짜 선택기 예시에서 스킬이 없으면 335줄, 있으면 이미 있는 브라우저 기능을 써서 10줄입니다

## 벤치마크 숫자는 맞았습니다

- 저장소가 공개한 테스트를 그대로 돌렸고, 주장 대비 코드 53% 감소는 61%, 비용 26% 절감은 24%, 속도 41% 향상은 35%였습니다. 버전 4.13보다는 약 11% 쌌습니다

## 일곱 단어 프롬프트와의 대결

- agents.md에 "YAGNI 원칙을 따르고 한 줄짜리 해법을 선호하라"는 일곱 단어만 넣은 경우와 비교했습니다. 코드는 Ponytail 60% 대 72%, 비용은 24% 대 38% 감소로 일곱 단어가 앞섭니다
- 하지만 "X를 만들어 줘" 24개 테스트에서는 일곱 단어 프롬프트가 데이터 손실 버그를 두 번 넣었고 Ponytail은 0건이었습니다
- 테스트를 남긴 비율은 24건 중 14건 대 24건, 명세 충족은 89% 대 95%, 핵심 기능은 97% 대 100%, 건너뛴 것을 알려 준 비율은 절반 대 70%였습니다. 그래서 Ponytail이 완전한 과잉 설계는 아니라고 봅니다

## 코드 품질은 일반 Claude와 비슷합니다

- 351개 코딩 작업을 블라인드 감사자가 점검했고 거의 모두 통과했습니다. 구독자 주소를 숨기고 메일을 보내는(BCC) 작업은 일반 Claude 3번 중 2번, Ponytail 1번, 이전 버전과 일곱 단어 프롬프트는 3번 모두 실패했습니다
- 트릭 입력 145개 시험에서는 일반 Claude 100%, Ponytail 59.5, 일곱 단어 프롬프트 98.4였습니다

## 모호한 요구에서 갈립니다

- 명세가 아주 상세한 PRD형 프롬프트에서는 Ponytail이 정확하고 간결하게 해냅니다
- "랜딩 페이지를 만들어 줘"처럼 모호하면 Opus 5.5는 알아서 조사하고 있으면 좋은 기능을 채우지만 Ponytail은 시킨 것만 합니다
- 있으면 좋은 기능 충족률은 일반 Claude 82%, Ponytail 41%, 일곱 단어 프롬프트 46%, 다듬으라고 덧붙인 Ponytail 63%입니다. 다듬으라고 하면 비용이 오히려 늘었습니다
- 요금 페이지 예시에서 일반 Claude는 내비게이션 바, 비교표, FAQ 등을 넣었지만 Ponytail은 모두 뺐습니다. 다듬은 Ponytail은 209줄에 50센트, 일반 Claude는 32센트였습니다

## 결론과 권고

- 숫자는 사실이지만 공개된 벤치마크는 이런 차이를 잘 반영하지 못한다고 합니다
- 원하는 바와 방법을 정확히 아는 사람은 쓰고, 빈틈을 Claude가 채워 주길 기대하는 대부분의 사람에게는 맞지 않는다고 봅니다. 아주 미세한 수정에서는 스킬 전체가 컨텍스트에 올라가 오히려 비용과 시간이 더 들 수 있습니다
- 전역 설치 대신 프로젝트 하나에서 직접 시험해 보라고 권합니다
- 코드를 절반으로 줄인다는 식의 스킬은 에누리해서 들어야 하며, 그렇게 쉬운 해법이라면 Anthropic이나 Codex가 이미 기본 기능으로 넣었을 거라는 것이 발표자의 의견입니다
