# 한국어 번역

매주 개발자들은 강력한 오픈소스 개발 도구를 내놓습니다. 이번 주 영상은 코딩 에이전트, 에이전트 스킬, 백엔드 플랫폼, 오브젝트 스토리지, 저장소 다이어그램 등 인기 프로젝트를 소개합니다.

## 1. Security Audit Skill

Cloudflare의 스킬로 코딩 에이전트가 구조화된 코드베이스 보안 감사를 수행하게 합니다. 여섯 단계로 코드를 파악하고 격리된 하위 에이전트가 문제를 찾은 뒤 별도 에이전트가 각 발견 사항을 반박하도록 해, 찾는 에이전트와 확인하는 에이전트를 분리합니다. 결과를 기계 판독 가능한 기록으로 남기고 확인됨, 검증 필요, 기각으로 나누며 실제 영향에 따라 심각도를 정합니다. 위험한 대상 코드는 샌드박스에서 실행합니다. MIT 라이선스입니다.

## 2. Agent Skills

영상에서 여러 번 소개되는 25개 엔지니어링 스킬 모음입니다. 명세부터 출시까지 시니어 엔지니어의 작업 절차를 코딩 에이전트에 적용합니다. 정의, 계획, 구현, 테스트, 검토, 출시를 위한 9개 슬래시 명령이 있고 작업에 따라 자동 활성화됩니다. 각 스킬은 단계, 검증 관문, 지름길 방지 규칙을 담습니다. Claude Code, Cursor, Codex 등 다양한 에이전트에서 쓸 수 있고 MIT 라이선스입니다.

## 3. Claude Code

Anthropic의 터미널 기반 에이전트 코딩 도구입니다. 자연어 요청으로 코드베이스를 이해하고 일상 작업, 복잡한 코드 설명, Git 작업을 수행합니다. 터미널, IDE, GitHub에서 사용할 수 있습니다. 플러그인으로 사용자 명령과 에이전트를 추가하고 외부 도구와 연결합니다.

## 4. Bend

AI가 작성한 코드의 실수를 수학적 증명으로 막으려는 빠른 병렬 프로그래밍 언어입니다. 앱이 어기면 안 되는 규칙을 laws 파일에 선언하면 컴파일러가 각 변경에서 규칙이 유지되는지 증명을 요구합니다. Python과 비슷한 문법 및 종속 타입을 사용하고 CPU·GPU 코어에서 코드를 실행합니다. Apache 2.0이며 아직 초기 단계입니다.

## 5. AuK 음성 모델

Tencent의 오픈소스 15억 매개변수 모델로 자연어 지시를 통해 음성을 생성하고 편집합니다. 제로샷·설명 기반 TTS, 말한 내용 편집, 음높이·속도·볼륨·감정·음색·억양 조정, 음성 향상과 화자 분리를 지원합니다. Nvidia GPU에서 CLI, 웹 데모, ComfyUI, Python으로 실행할 수 있으며 빠른 증류 버전은 MIT 라이선스입니다.

## 6. SoLPi

Pi 코딩 에이전트용 Nvidia 확장으로 실제 작업을 줄이지 않고 장기 작업의 토큰 낭비를 줄입니다. 네 가지 효율 기능을 선택적으로 켭니다. 편집 호출 안에서 후속 검증 명령을 실행하고, 반복되는 큰 결과를 나중에 다시 불러올 핸들로 바꾸며, 원문과 인용이 일치할 때만 긴 로그를 요약하고, 완료된 계획 단계는 컨텍스트에서 줄입니다. MIT 라이선스입니다.

## 7. Codex Astra Orchestrator

두 모델을 사용하는 Codex 설정입니다. 강한 Astra 모델은 오케스트레이터로 계획과 통합을 맡고 Luna 모델은 전문 하위 에이전트로 실제 작업을 합니다. 탐색가, 작업자, 테스터, 검토자, 연구자 역할 파일이 포함되며 각 역할은 Luna 모델에 고정됩니다. 설정을 프로젝트나 전역 환경에 복사해 추론 노력과 동시성을 조정합니다.

## 8. Zetta

기반 모델을 고정한 채 로봇 정책을 온라인으로 개선하는 폐루프 구현형 하네스입니다. 재학습하는 대신 코드 기반 런타임 비평가와 복구 스킬을 만들며 세 가지 시간 규모의 루프로 행동 빈도를 제어하고 실패한 실행에서 수정안을 만든 뒤 같은 시드와 보류 검증을 통과해야 반영합니다. Libero, Robocasa 등 시뮬레이션 로봇 벤치마크를 대상으로 하는 연구 프로젝트입니다.

## 9. Rune

GPU 가속 IDE와 터미널 멀티플렉서를 결합한 개발 환경입니다. Electron이 아닌 네이티브 앱으로 만들어 수동 코딩과 AI 에이전트 제어 모두에 맞습니다. 워크스페이스, 터미널, 탭, 창을 유연하게 배치합니다. 각 인스턴스는 종단 간 암호화된 피어 네트워크를 만들며 공식 또는 Git 저장소의 Go 플러그인으로 확장합니다. GPL 3.0입니다.

## 10. OpenSpec

AI가 코드를 쓰기 전에 사람과 AI가 명세에 합의하도록 하는 가벼운 명세 주도 개발 도구입니다. 슬래시 명령으로 아이디어를 탐색하고 제안서, 구체적 시나리오가 있는 Markdown 요구사항, 설계, 작업 체크리스트를 변경 폴더에 만듭니다. 구현 전에 검토하고 완료한 변경은 보관하며 명세를 갱신합니다. 30개 이상 AI 도구를 지원하고 팀의 저장소 간 계획을 공유할 수도 있습니다. Node 기반 MIT 라이선스입니다.

## 11. Anki

간격 반복 플래시카드 프로그램입니다. 모든 카드를 똑같이 복습하는 대신 사용자가 얼마나 잘 아는지에 따라 복습 시기를 잡아 잊기 직전에 보여줍니다. 컴퓨터 버전 저장소는 Rust, Python, TypeScript로 만들어졌으며 모바일·웹 앱과 동기화합니다.

## 12. RustFS

Rust로 만든 S3 호환 분산 오브젝트 스토리지이며 메모리 안전성과 Apache 2.0 라이선스를 내세운 MinIO 대안입니다. 기존 S3 클라이언트가 사용할 수 있고 MinIO나 Ceph와 마이그레이션하거나 함께 쓸 수 있습니다. 버전 관리, 버킷 복제, 이벤트 알림, 비트 로트 보호, 멀티테넌시, OpenStack Swift·Keystone 프로토콜을 제공합니다. 단일 노드와 분산 모드를 지원하며 스크립트, Docker, Helm, Nix로 설치하고 웹 콘솔에서 관리합니다.

## 13. Supabase

Firebase의 오픈소스 대안으로 소개되는 Postgres 기반 개발 플랫폼입니다. 웹·모바일·AI 앱을 위한 전용 Postgres 데이터베이스에 인증, 자동 REST·GraphQL API, WebSocket 실시간 구독, 파일 저장소, 엣지 함수, 임베딩용 벡터 도구를 더합니다. 대시보드에서 관리하며 여러 오픈소스 도구로 구성됩니다. 호스팅 또는 자체 호스팅이 가능하고 Apache 2.0입니다.

## 14. GitDiagram

공개·비공개 GitHub 저장소의 구조를 대화형 아키텍처 다이어그램으로 바꿉니다. 저장소 트리와 README를 읽어 AI 모델이 자연어 설명을 만들고 검증된 시스템 그래프를 생성합니다. 구성요소를 누르면 GitHub의 실제 파일이 열립니다. 저장소 URL의 `hub`를 `diagram`으로 바꾸어 열 수 있습니다. 비공개 저장소는 로컬 토큰을 사용하며 Mermaid 또는 PNG로 내보낼 수 있습니다. Next.js·MIT 라이선스입니다.

## 15. Bird's Eye View

AI가 코드를 바꾸기 전에 프로젝트 아키텍처를 그려 어떤 모듈이 변경될지 확인하게 하는 스킬입니다. 아키텍처 파일과 에이전트가 밝힌 작업 범위를 받아 모듈, 담당 영역, 근거, 계획 범위를 보여주는 대화형 HTML을 만듭니다. 아키텍처, 변경, 비교 화면을 제공합니다. 입력을 JSON 스키마로 검증하고 `agents.md` 지침을 통해 어떤 에이전트와도 쓸 수 있습니다. Node 기반 MIT 라이선스입니다.

## 16. VideoGen Client

SeaDance, Kling, Minimax/Hailuo, Vyan 등 여러 AI 영상 생성 서비스에 하나의 비동기 Python 인터페이스를 제공합니다. 제공자 API를 각각 익히지 않고 텍스트-영상 또는 이미지-영상 클립을 생성할 수 있습니다. CLI는 모델 목록 확인, 작업 시작, 진행 상태 조회를 제공하며 로컬 FastAPI 웹 UI에서 모델과 프롬프트를 고르고 MP4를 내려받을 수 있습니다. MCP 서버도 포함하며 MIT 라이선스입니다.

## 17. AgentVerse OS

Ubuntu 서버 하나에서 개발자와 에이전트를 위한 개인 클라우드 운영체제입니다. 한 명령으로 설치하면 노트북, 태블릿, 휴대전화에 맞춰지는 브라우저 데스크톱이 제공됩니다. 프로젝트별 격리 작업 공간과 브라우저 VS Code, Claude Code, Codex, 자체 호스팅 앱 스토어, 백업, 업데이트를 포함합니다. Tailscale을 통해서만 접근해 인터넷에 서비스를 직접 공개하지 않습니다. Rust 코어·Svelte UI, Apache 2.0 알파입니다.

## 18. Page Mascot

웹페이지에 커서를 따라 움직이는 캐릭터를 넣는 작은 웹 컴포넌트입니다. 캐릭터는 두 스프라이트 시트와 아홉 방향·아홉 표정으로 구성되고 커서 방향에 따라 고개를 돌리며 클릭하면 반응합니다. npm으로 설치하고 준비된 캐릭터를 쓰거나 스킬로 직접 시트를 만들 수 있습니다. 동작 감소 설정과 정밀 포인터 설정을 존중하며 MIT 라이선스입니다.

## 19. TypeSafe Computer Use

큰 모델에 스크린샷을 보내지 않고 저렴하게 Mac을 제어합니다. OCR과 접근성 데이터를 이용해 화면을 결정론적으로 읽고 작은 TypeSafe 분류기가 클릭, 스크롤, 사이트 열기 같은 고정 동작 목록 중 다음 동작을 고릅니다. 자유 텍스트가 꼭 필요한 입력란에서만 작성 모델을 호출합니다. 각 단계에서 주석이 달린 스크린샷과 입력 데이터를 기록해 재생할 수 있습니다. Python·macOS 전용, MIT 라이선스입니다.
