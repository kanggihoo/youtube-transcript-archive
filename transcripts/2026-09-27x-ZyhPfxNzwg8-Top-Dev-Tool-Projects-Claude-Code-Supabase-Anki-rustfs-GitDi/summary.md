# 영상은 코딩 에이전트, 에이전트 스킬, 저장소 이해, 백엔드·스토리지 등 19개 개발 도구를 빠르게 훑는다. 탐색 출발점으로 활용하고, 라이선스와 지원 범위, 프로젝트의 현재 상태는 개별 저장소에서 확인해야 한다.

## 에이전트 개발 흐름

Security Audit Skill은 발견과 반박 검토를 분리한 보안 감사를 수행한다. Agent Skills와 OpenSpec은 구현 전후의 엔지니어링 절차와 명세를 돕고, Codex Astra Orchestrator는 모델별 역할을 나눈다. SoLPi는 장기 실행 중 로그·계획 컨텍스트를 정리한다.

## 코드베이스와 개발 환경

GitDiagram과 Bird's Eye View는 저장소 구조와 변경 범위를 시각화한다. Claude Code와 Rune은 코딩 환경을 제공하고, Bend는 규칙을 증명하는 컴파일을 목표로 한다. AgentVerse OS는 브라우저에서 접근하는 개인 개발 환경을 제안한다.

## 인프라·데이터·콘텐츠 도구

RustFS는 S3 호환 스토리지, Supabase는 Postgres 기반 백엔드, Anki는 간격 반복 학습을 제공한다. AuK와 VideoGen Client는 음성·영상 생성, TypeSafe Computer Use는 Mac UI 자동화를 다룬다.
