# I Tested Sonnet 5.5 vs Opus 5.5. What You Need to Know.

### 한 줄 요약

목표와 완료 기준이 명확한 작업은 절반 가격의 Sonnet 5.5로, 모호하고 창의성이 필요한 작업은 Opus 5.5로 맡기라는 것이 일곱 가지 실전 비교에서 나온 결론입니다.

### 가격과 모델 선택 기준

- Sonnet 5.5는 입력 100만 토큰당 2달러, 출력 10달러이고 Opus 5.5는 각각 4달러, 20달러라 Opus가 대략 두 배 비쌉니다. 발표자는 "Opus가 두 배 좋은가"를 확인하려 했습니다
- 발표자에 따르면 Sonnet 5.5는 Sonnet 5보다 30% 빠르고 대부분의 작업에서 30% 저렴합니다
- Anthropic 가이드: 범위가 잡힌 일상 코딩, 버그 수정, 문서, 슬라이드, 스프레드시트는 Sonnet, 신중한 판단이 필요한 장기 에이전트형 작업과 가장 어려운 문제는 Opus
- 발표자의 해석: 객관적인 완료 기준이 있으면 Sonnet부터 시도하고, 완료 기준부터 함께 정해 줄 생각의 파트너가 필요하면 Opus를 씁니다. 스킬마다 모델을 돌려 보고 어느 쪽이 나은지 기록해 두라고 권합니다
- 모든 테스트는 같은 프롬프트, 둘 다 high 노력 수준, 병렬 실행이며 비용은 구독 사용량이 아닌 API 요금 기준으로 봤습니다

### 일곱 가지 테스트 결과

- **웹사이트 디자인 (Sonnet 승)**: 퍼크폼 랜딩 페이지. Sonnet은 히어로 섹션이 인상적이었지만 캔을 3D로 지어냈고, Opus는 실제 생성 이미지를 브랜드 가이드라인대로 써서 전체적으로 나았습니다. 다만 Opus는 52분에 약 두 배 비용(약 13달러)이라, Sonnet에 실제 이미지를 쓰도록 다시 시키면 될 것이라며 Sonnet에 승을 줬습니다
- **모션 디자인 (Opus 승)**: 글리도 모션 쇼릴. Sonnet도 기대 이상이었지만 Opus가 배경, 애니메이션, 카피, 사운드 디자인에서 더 글리도다웠고 웹사이트의 실제 인용문까지 가져왔습니다. Sonnet 14.37달러, Opus 20.55달러
- **90일 실행 계획 (Opus 승)**: 구독자 1,000명 목표의 모호한 프롬프트. Opus는 4분기에 맞춘 월 단위 뷰와 체크할 수 있는 구체적 작업 문서를 줬습니다. Opus 20분, 9달러 남짓, Sonnet 14분, 5달러 미만. 구체적인 프롬프트였다면 결과가 비슷했을 것이라고 봅니다
- **스프레드시트와 투자자 덱 (Opus 승)**: 두 모델 결과물이 거의 같았고 둘 다 셀에 수식을 넣었습니다. 이번에는 Opus가 더 싸고 더 빨라서 Opus가 이겼습니다. 스킬은 쓰지 않았습니다
- **PC에서 돌릴 AI 설명 (Sonnet 승)**: HTML 익스플레이너 스킬 사용. 설명력은 Opus가 낫고 시각화는 Sonnet이 나았습니다. Sonnet은 비용이 절반이라 한 번 더 프롬프트하면 Opus보다 나아질 것이라며 Sonnet에 줬습니다
- **AI 뉴스 대시보드 (Sonnet 승)**: X 스크래핑 대시보드. Opus가 더 시각적이고 좋았지만 약 7분 더 걸리고 6달러 더 들었습니다. Sonnet은 원하는 것을 그대로 주는 기본선 수준이고, 목표가 명확하면 반복해서 같은 수준에 도달할 수 있다고 봅니다
- **유튜브 리소스 가이드 (Sonnet 승)**: 자주 쓰는 스킬이 있어서 두 결과물이 거의 같았고 Sonnet이 두 배 빠르고 1.40달러 저렴했습니다. 스킬이 기준을 정해 주면 덜 똑똑한 모델도 지시를 따를 수 있다는 예입니다

### 종합과 결론

- 전적은 Sonnet 4승, Opus 3승이지만 정면 대결이 아니라 언제, 어떻게 쓸지 보려는 실험이었다고 밝힙니다
- 일곱 세션 합계로 Opus는 약 46분 더 오래 돌았고 입력 토큰을 약 3,800만 개 더 썼으며 출력 토큰은 오히려 적었습니다. 비용은 약 16달러 더 들었는데, 가격이 두 배인 것에 비하면 실험에서는 그만큼 벌어지지 않았습니다
- 패턴: 원하는 것이 명확하면 Sonnet이 충분하고, 열린 목표를 맡기면 Opus가 더 잘 처리합니다
- 결국 자신의 스킬, 프롬프트, 프로세스로 직접 테스트해 봐야 합니다
