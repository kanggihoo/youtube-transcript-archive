# 클로드 코드에 택시 미터기 달았습니다 | Claude Mods 직접 만드는 법

## 한 줄 요약

Claude Code의 새 기능 Mods(모드)는 화면 일부를 새로 그리거나 이벤트에 끼어드는 플러그인이며, 어디에 무엇을 어떤 데이터로 보여줄지 프롬프트로 설명하면 Claude Code가 바로 만들어 줍니다. 발표자는 토큰 사용량만큼 요금이 오르는 택시 미터기 모드로 시연합니다.

## 모드는 훅이 못 하던 일을 한다

모드는 JavaScript/TypeScript와 이벤트 핸들러로 이루어진 플러그인입니다. Claude Code가 특정 이벤트에서 핸들러를 부르면 핸들러가 그 이벤트를 관찰, 수정, 처리합니다.

기존 훅과의 차이가 요점입니다. 훅은 설정 파일에 적은 셸 명령을 Claude Code **바깥에서** 실행합니다. 모드는 직접 만든 함수나 셸 스크립트를 Claude Code **안에서** 실행합니다. 그래서 훅, 스킬, MCP로는 안 되던 인터페이스 다시 그리기가 됩니다. 터미널뿐 아니라 데스크톱 앱에서도 동작합니다.

## 택시 팩 시연

GitHub에 올려 둔 플러그인을 `claude plugin marketplace add`로 마켓플레이스를 추가한 뒤 `claude plugin install`로 설치합니다.

- **택시 미터기** — 모델 가격 기준으로 지금까지 쓴 토큰을 API 요금으로 환산해 표시. 응답 전 Empty, 생성 중 Driving, 끝나면 Payment에서 최종 요금. 모델별 할증(Opus는 Deluxe, 그 외는 Standard 등)과 컨텍스트 50% 초과 시 Complex 표시
- **내비게이션** — 요청을 경유지로 나눠 음성으로 안내하고, 경유지를 추가하면 개수가 늘며, 마지막에 목적지 도착으로 종료
- **단속 카메라** — 강제 push나 폴더 삭제 같은 위험한 Bash 명령 직전에 개입해 권한 요청을 모드로 처리
- **블랙박스** — 우측 패널에서 도구 호출 기록과 훅 수준에서 잡힌 사건을 확인

## 내 모드 만드는 법

Claude Code 2.1.28 이상이면 됩니다. 프롬프트에 담을 것은 네 가지입니다.

1. 모드를 **어디에** 둘지
2. **무엇을** 보여줄지
3. 데이터를 **어디서** 가져올지
4. 끝났을 때와 실패했을 때 어떻게 할지

영상의 예시는 단계별로 쌓아 갑니다.

1. 스피너 옆에 현재 요청 비용을 원화로 표시(환율 1,400원 지정). 만들다 핫 리로드를 묻는 창에서 Enter 대신 이번 세션에 켜는 두 번째 옵션을 선택
2. 프롬프트 위 밴드에 "현재 요청 비용, 5시간 한도 사용률, 리셋 시각"을 한 줄로 표시. 다른 모드가 그린 것을 가리지 않도록 요청
3. 밴드를 택시 미터기처럼 꾸밈: 둥근 테두리 박스, 검은 배경, 블록 문자로 만든 LED 요금 숫자, 하단 Empty/Driving/Pay 표시
4. `/receipt` 명령을 추가해 영수증을 우측 패널에 표시

## 주의점

- 블록 문자 그래픽은 터미널에서만 지원됩니다. 터미널이 아니거나 창이 좁으면 한 줄로 표시하도록 프롬프트에 미리 요청해 둡니다
- 만든 모드는 연 세션에서만 돕니다. 모든 세션에서 쓰려면 폴더를 빼내 `--plugin-dir`로 실행하거나, 저장소에 올려 마켓플레이스로 설치합니다

## 모드를 둘 수 있는 영역

- **밴드** — 프롬프트 입력창 바로 위
- **패널(pane)** — 넓은 전체 화면에서는 대화 옆 사이드바, 아니면 프롬프트 위 창
- **스피너** — Claude가 작업 중일 때 움직이는 줄
- 그 밖에 대화 영역의 도구 실행 줄과 결과 창, 대화 메시지, 질문 창, 진행 표시, 프롬프트 아래 힌트, 로고 아래 안내. 프롬프트 영역 자체는 수정할 수 없습니다
