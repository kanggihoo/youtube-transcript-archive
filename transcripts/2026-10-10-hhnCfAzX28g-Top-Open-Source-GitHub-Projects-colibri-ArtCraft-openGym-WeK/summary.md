# Top Open-Source GitHub Projects : colibri, ArtCraft, openGym, WeKnora, SCSKiller & Whirl #299

## 한 줄 요약

ManuAGI가 이번 주 인기 오픈소스 GitHub 프로젝트 20개를 프로젝트당 30초에서 1분 안팎으로 훑는 주간 업데이트로, 에이전트용 스킬과 플러그인, 로컬 추론, 셀프 호스팅 앱이 고루 섞여 있습니다.

## 코딩 에이전트용 스킬과 플러그인

- diagram-design: 27가지 유형의 편집 품질 다이어그램을 독립 HTML과 SVG로 만드는 Claude Code 스킬입니다. 사이트에서 색상과 글꼴을 읽어 브랜드에 맞추고 PNG나 SVG로 내보냅니다
- Cursor plugins: Cursor 플러그인 사양과 공식 플러그인 저장소입니다. 스킬, 규칙, MCP 서버 정의를 묶습니다
- Open Code Review: Alibaba의 AI 코드 리뷰 CLI로, 결정적 파이프라인과 LLM 에이전트를 결합해 줄 단위 코멘트를 달고 자동 수정도 합니다
- i-have-adhd: 서론을 빼고 다음 행동부터 말하며 번호 단계와 구체적 시간 추정, 다음 단계 하나로 끝내게 하는 규칙 10개입니다
- Vibewise: 코드를 쓰기 전에 설계 체크포인트와 단계별 사고를 강제해 AI와 만들면서 배우게 하는 Claude Code 플러그인입니다

## 에이전트 운영과 모델

- Paperclip: 에이전트를 직원처럼 두고 목표, 예산, 승인 게이트, 감사를 관리하는 Node.js와 React 기반 셀프 호스팅 앱입니다
- WeKnora: Tencent의 지식 플랫폼으로 RAG 질의응답, ReACT 에이전트, 자동 유지되는 Markdown 위키 모드를 제공합니다
- colibri: 의존성 없는 C 파일 하나의 추론 엔진으로, MoE 모델의 활성 부분만 RAM에 두고 나머지는 디스크에서 스트리밍해 대형 모델을 일반 PC에서 돌립니다
- Decider와 Strands Decider: 한 번의 패스로 보정된 확률과 분류된 답을 내는 의사결정 모델(8B에서 35B MoE)과, 에이전트의 도구 호출을 예/아니오로 통제하는 2B 모델입니다

## 셀프 호스팅 앱과 창작 도구

- ArtCraft: 모델 62개 카탈로그로 이미지, 영상, 음악, 3D를 한 캔버스에서 만드는 Rust와 Tauri 데스크톱 스튜디오입니다
- Open Gym: 데이터를 내 폴더에 두는 운동 기록 앱으로, 점진적 과부하 계산과 FitNotes, Strong, Heavy 가져오기를 지원합니다
- Whirl: 메모리, 문서, MCP 도구를 갖춘 world.chat의 전체 코드로, Next.js와 Convex 기반 MIT 라이선스입니다
- MotionFlow OSS: Claude로 모션 영상을 단계별 승인과 함께 만드는 로컬 스튜디오입니다

## 그 밖의 도구와 자료

- SCSKiller: 게임이 꺼진 동안 셰이더를 미리 컴파일해 끊김을 줄이는 Windows 도구입니다. 안티치트 게임은 건너뜁니다
- OpenAI math: 내부 모델이 만든 수학 원고 722편이 담긴 저장소로, 다수에 Lean 증명이 있으나 기계 생성물이며 동료 심사를 거치지 않았습니다
- Field Watch: 송신 없이 Wi-Fi와 BLE를 수신만 하고 드론 Remote ID를 해독하는 Android 앱입니다
- REDox: Capcom의 .NET용 구조화 데이터 엔진으로 JSON, CBOR, TOML, XML 등 여러 형식을 다룹니다
- C64 Keyboard Font: Commodore 64 키캡 기호를 복원한 퍼블릭 도메인 글꼴입니다
- Muse Gadgets: Meta의 Muse를 구동하는 ESP32와 Raspberry Pi 기기용 SDK입니다
