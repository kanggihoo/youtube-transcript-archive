# 마지막 인간 코드 리뷰: AI가 생성한 코드에 신뢰를 쌓는 방법 — 이타마르 프리드만, Qodo

## 한 줄 요약

AI가 생성한 코드가 사람의 리뷰 속도를 추월한 시대에는 모델 추론이 아니라 조직의 암묵지와 아키텍처 의존성을 '컨텍스트 엔진'으로 코드화해야 코드 리뷰를 안전하게 자동화할 수 있다.

## 병목은 모델 성능이 아니라 컨텍스트와 거버넌스

최신 모델들이 쏟아져 나와도 코드 리뷰 벤치마크 점수는 크게 달라지지 않았습니다. 코드 리뷰의 성패는 모델 추론 능력이 아니라 **올바른 컨텍스트의 유무**에 달려 있습니다. 컨텍스트가 없으면 최고 수준의 모델도 단순한 에러 처리 유무 같은 피상적인 지적에 그칩니다.

현재 조직의 지식은 `agents.md`, `claude.md`, `skills/` 등으로 파편화되어 팀 간 표준이 일치하지 않고 일관된 신뢰를 확보하기 어렵습니다.

## 코드 리뷰의 두 축과 자동화 조건

코드 리뷰는 두 가지 역할을 합니다:
1. **품질/안전성/아키텍처 검증**
2. **조율(Alignment)과 팀 학습** (시니어 개발자의 교육 및 최종 게이트키핑)

인간의 리뷰를 생략하고 자동 승인/차단 단계로 나아가려면 다음 인프라가 필수적입니다:

- **인간용 인터페이스**: 어떤 규칙과 표준을 검사했고 위반했는지 투명하게 근거와 링크 제공
- **에이전트용 인터페이스**: 리뷰 에이전트가 다른 에이전트에게 구체적인 위반 사항을 전달하고 수정 diff를 체리픽할 수 있는 구조
- **점진적 자동화**: 인간의 개입 없이 규칙을 통과한 PR이 100건 이상 누적되면서 차단/승인 규칙을 단계적으로 확장

## 소프트웨어 그래프와 자가 학습 컨텍스트

단순한 린트 규칙 수준을 넘어, 조직의 진짜 암묵지는 **시스템 아키텍처와 장애 히스토리**에 있습니다.

- **서비스 간 계약(Contract) 그래프**: 마이크로서비스 간의 의존성과 계약 관계를 그래프 노드/엣지로 구조화
- **장애 및 토론 히스토리 학습**: 과거 프로덕션 장애(P0)를 일으킨 원인 분석, PR 토론에서 합의된 결정 사항을 지식으로 축적
- **다중 PR 충돌 조망**: 동시에 진행 중인 여러 PR이 서로 다른 브랜치에서 동일한 계약이나 에이전트를 깨뜨릴 위험을 소프트웨어 그래프 관점에서 사전 감지

## 인공지능(AI)에서 인공지혜(Artificial Wisdom)로

현재 코드의 좋고 나쁨을 가르는 궁극적인 '판단력(Judgment)'은 개발자의 머릿속에 있습니다. 이 암묵지를 체계적으로 코드화하여 AI 시스템으로 이관할 때 진정한 코드 거버넌스 자동화와 10배의 개발 생산성을 달성할 수 있습니다.
