# 에이전트는 LLM만으로 완성되지 않는다. 메모리 저장과 검색, 도구 연결, 컨텍스트 선택, 제한된 실행 루프를 하네스로 설계해야 반복 가능한 결과를 얻을 수 있다.

## 데이터와 메모리 설계

에이전트 스택의 여러 계층 중 데이터는 개발자가 통제할 수 있는 중요한 부분이다. 파일은 유연하고 데이터베이스는 구조·검색에 강하므로 저장 방식을 작업에 맞게 조합할 수 있다. 조직 고유 지식과 용어도 모델이 찾을 수 있게 표현해야 한다.

## 하네스의 핵심 구성

하네스는 저장소, 메모리 인코딩·검색·회수, 시맨틱 지식, MCP와 도구, 에이전트 루프, 컨텍스트 엔지니어링으로 구성된다. 도구 결과를 되돌려 반복하되 호출 한도와 중단 조건을 두고, 현재 과제에 필요한 맥락만 컨텍스트 창에 남긴다.

## 확장과 실습

수천 개 도구는 벡터 검색 기반 계층적 도구 상자에서 선택할 수 있다. 도구 호출 한도, 오류 복구, 모델 라우팅으로 비용과 재시도를 관리한다. 워크숍은 기본 모델 호출부터 시작해 이러한 하네스 구성요소를 하나씩 구현한다.
