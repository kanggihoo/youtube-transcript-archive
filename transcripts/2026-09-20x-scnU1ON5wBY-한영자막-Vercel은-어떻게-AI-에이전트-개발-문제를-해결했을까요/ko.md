### 에이전트를 위한 Next.js, 'Eve'

**11:51** · 그렇게 탄생한 아이디어가 바로 "에이전트를 위한 Next.js"입니다.

**11:56** · Next.js는 Vercel이 만든 대표적인 웹 프레임워크입니다. 파일 시스템 규칙만 지키면 CDN, 서버리스 함수, 캐싱 인프라가 자동으로 구성되는 프레임워크 정의형 인프라를 창시했습니다.

**12:19** · 에이전트 구축도 이처럼 단순해야 합니다. `skills/`, `tools/`, `channels/` 폴더만 만들고 선언하면 프레임워크가 알아서 완전한 에이전트로 조립해 주어야 합니다.

**12:32** · 그래서 2주 전, 저희는 에이전트 프레임워크 'Eve'를 출시했습니다. 에이전트를 위한 Next.js로서, 템플릿 하나로 커스텀 지식과 도구를 붙여 즉시 프로덕션 에이전트를 완성할 수 있습니다.

**12:51** · 에이전트는 런타임과 채널로 구성됩니다. 런타임은 내구성(Durability), 격리된 샌드박스 실행, 다중 모델 라우팅, 외부 시스템 연결을 필요로 합니다.

**13:05** · Eve는 철저한 오픈소스 기반입니다. Postgres, OpenAI Responses API, Docker 등 원하는 어댑터를 자유롭게 연결할 수 있습니다.

**13:16** · 동시에 Vercel 인프라 위에서 원클릭 배포가 가능합니다. 지속성을 위한 Vercel Workflows, 안전한 격리를 위한 Sandbox, 최근 발표된 OIDC 인증용 Vercel Connect가 유기적으로 맞물려 돌아갑니다.

**13:38** · 저희는 사내 D0 데이터 에이전트 전체를 Eve 기반으로 완전히 재작성했습니다.

**13:49** · 시스템 프롬프트, 스킬, 도구가 폴더 단위로 깔끔하게 모듈화되어 확장이 매우 쉽습니다.

**13:59** · 2주 전 런던 행사에서 정식 공개하기 전 베타 고객들에게 먼저 제공했습니다. 파트너사인 Aura는 외부 웹사이트를 자율 탐색하고 테스트하는 미니 Claude 형태의 에이전트를 기존 Claude Code 기반에서 Eve 기반으로 재구축했습니다.

### 초기 도입 성과와 시작하는 방법

**14:17** · 순정 Claude Code 대비 단계 수 단축, 성공률 향상, 정밀한 인사이트 도출 등 압도적인 성과를 거두었습니다.

**14:32** · Eve를 Vercel에 배포하면 별도 설정 없이 완벽한 관측성(Observability)이 제공됩니다. 모든 실행 흐름, 도구 호출, 스텝별 추론 과정, 예상 비용과 최적화 포인트를 대시보드에서 한눈에 볼 수 있습니다.

**14:47** · 지금 바로 `eve.dev`에서 템플릿을 복제해 시작할 수 있으며 자체 호스팅도 지원합니다.

**14:55** · 기업들이 자사 고유의 비즈니스 지식을 담은 맞춤형 에이전트를 적극적으로 구축하기를 권장합니다.

**15:02** · D0를 만들기 전 저희도 외부 스타트업들의 기성 데이터 에이전트를 테스트해 보았지만 만족스럽지 않았습니다. 에이전트의 성패를 가르는 진짜 핵심은 '사내 고유의 비즈니스 맥락'에 있기 때문입니다.

**15:38** · 기성 범용 에이전트만으로는 한계가 있습니다. 기업 특유의 도메인 지식과 스키마 규칙을 담아 자체 에이전트를 만들어야 진정한 가치가 폭발합니다.

**15:51** · 현재 Vercel 사내에는 마케팅 분석, 법무팀 계약서 1차 검토, 데이터 사이언스 질의 등 20여 개의 실전 에이전트가 가동 중입니다.

**16:12** · 이 에이전트들은 막대한 시간을 절약해 주고 있습니다. 데이터 팀은 반복 쿼리 작성에서 해방되어 Snowflake 성능 튜닝과 데이터 파이프라인 확장에 집중할 수 있게 되었습니다.

**16:45** · 인사, 재무, 영업 등 수많은 반복 업무를 에이전트로 자동화할 수 있으며, Eve가 가장 완성도 높은 시작점이 될 것입니다.
