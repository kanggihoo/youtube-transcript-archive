# Elasticsearch는 대량 데이터를 미리 인덱싱해 빠르게 검색하고 분석하는 분산 엔진이다. 관련도 순위·오타 허용·필터·집계·로그 분석을 제공하며, 단순한 범용 데이터베이스라기보다 검색과 분석에 최적화된 시스템이다.

## 인덱스로 빠른 검색

매번 모든 문서를 훑지 않고 검색에 맞춘 인덱스를 만든다. 오타 허용, 자동완성, 관련도 정렬과 필터를 결합해 상품·문서 검색에 활용할 수 있다.

## 문서·집계·로그

데이터는 JSON 문서로 저장하며 HTTP API로 여러 언어의 애플리케이션에서 접근한다. 집계로 평균이나 범주별 개수를 계산하고, 여러 서비스 로그를 모아 중앙 검색·관측성 도구로 쓸 수 있다.

## 분산 구조

Apache Lucene의 검색 기능을 바탕으로 Elasticsearch가 분산 노드와 API를 제공한다. 여러 머신에 데이터와 사본을 나눠 대용량 처리와 장애 대응을 지원한다.
