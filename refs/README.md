# refs

영상과 **별개로 존재하는** 외부 자료를 둡니다. 영상에서 언급된 저장소, 문서, 도구처럼 영상이 없어도 그 자체로 서는 것들입니다.

영상 폴더(`transcripts/<...>/`) 안에는 넣지 않습니다. 여러 영상이 같은 자료를 참조할 때 복사본이 생기기 때문입니다.

## 어느 영상과 연결되는지

[index.md](./index.md)에 자료별 출처와 참조하는 영상이 정리돼 있습니다.

## 자료를 추가할 때

1. `refs/<자료이름>/`에 놓습니다
2. `index.md`에 항목을 추가합니다 — 출처, 어느 영상에서 나왔는지, 무엇인지
3. 영상 쪽에서는 파일을 복사하지 말고 링크만 답니다

```markdown
관련 자료: [compound-engineering-plugin](../../refs/compound-engineering-plugin/)
```

읽기용 자료입니다. 이 프로젝트의 스킬이나 의존성으로 활성화하지 않습니다.
